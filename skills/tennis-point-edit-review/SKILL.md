# 网球逐分精剪、计分与复核

用于有连续比赛画面的网球单打录像。支持六局、四局、有占先、无占先、限时不限局、纯抢七及纯抢十；采用用户已给规则和下述默认值，只有影响结果且无法从素材核实的真实缺口才追问。不是比赛裁判或雷达测速工具。双打需要额外确认发球与接发顺序，再扩展规则，不能直接套用单打核算器。

## 工作原则：主动完成本阶段，再交付检查点

包版本 **2026.10.04-v23**。网球剪辑任务即使用户未手动点选本技能，也应按任务类型检索并加载；未另指定UI技能/模板/风格时，直接复用本包正式模板，禁止随机重设计。优先级为用户当前明确要求、项目已确认风格、本包默认。

- **从实际进度接续。** 先检查用户目标、已有工程和确认记录，选择尚未完成的阶段；复用已完成成果，不重做前序。首次回复通常用2–4句说明从当前起点到成片的流程、本轮产物与下一步；明确要求一口气完成、跳过介绍或上下文已表明熟悉本技能时可省略。继续、修正、回填不重复介绍。具体见[首次引导](references/onboarding.md)。
- **默认按阶段分轮交付。** 本轮完成当前阶段的实质工作和自检，以可检查的产物收尾，报告完成范围、剩余问题和下一阶段动作；大型阶段可按有明确范围的批次接续，不默认一轮包办整场。用户明确要求“一口气完成／连续执行，只在必要时问我”时才连续跨阶段；仍逐阶段读细则和自检。熟悉技能、说“直接开始”只省介绍，不自动等于连续模式。
- **检查点是结果汇报。** 确认的是已执行的工作与证据，不是让用户重复批准流程、样式或清晰球；不要以计划、候选列表或空白待核表冒充阶段完成。每阶段开始读该行必读细则，交付前逐项核对产物。续轮从保存的[阶段记录](references/workflow.md#阶段记录与接续)开始；不靠记忆越过细则。
- **判读与补查由agent负责。** 主动判断得分方、局界、发球方、发次及技术事件，证据足够就采用并记录依据。未检查属于待办；查过仍缺关键证据才是未知。先扩大原片、看连续帧和邻接上下文，再把仍影响结果的具体疑点交用户。未知只阻塞依赖它的结论，其他工作继续；不得为显得完成而猜数。

## 先区分对象与编号

| 对象 | 含义与范围 |
|---|---|
| 剪辑段 clip | 编辑器中的片段；一分可含多个片段，一发、二发、擦网不各算一分 |
| 逐分账本 / P编号 | 全部候选与真实分的稳定`pointId`及证据；P号用于定位，不等于有效分总数 |
| 主剪“第N分” | 当前版本有效计分顺序的`displayNumber`，连续1…N；增删合并后重生成，P号不改。分析中计分资格未定时先显示“定位 P…”而不冒称第N个有效分 |
| 人工复核子集 / R编号 | agent自行回查后剩余的实质疑点，及解决局内矛盾所必需的相关分；每行`R / P`。不是全场账本的复制品 |
| “所有行常显” | **已选入本轮人工复核的行**不因填写状态而隐藏；不要求把全场每分送审，也不改动正在使用的审核版本和草稿 |

## 开工与接续

先读[输入与规则](references/inputs-and-rules.md)和[编辑环境选择](references/editing-environments.md)：ChatCut、Premiere Pro、本地独立流水线是并列候选，按用户指定、已有工程及实测能力选择。编辑层与[图形层](references/graphics-adapters.md)分别选择；Pr读[Premiere分支](references/premiere-pro.md)，区分CEP/ExtendScript与UXP；本地模式读[工作台](references/local-editor.md)。终端与媒体检查能力即可启动，不以Computer Use为前提；缺少通路说明具体缺口，继续可独立完成的工作，不静默换编辑器。

默认从0:0第一分第一次发球开始；结束时暂按没有未完局并用尾段与计分链核验。未知持拍手只问一次，未答暂按右手并记录假设；已知左/右手不被默认值覆盖。最终比分未知也能开始。不能把默认、推定或“presumably”写成视觉已证实，不反复确认上述默认。使用 [正式模板清单](examples/ui-manifest.json) 与 [模板说明](references/visual-templates.md)。场景、规则或画幅需要适配时保持已确认视觉语言。声明可编辑属性并在目标项目实测后才交付。主比较行与组件数量由正式清单和 [版本元数据](references/package-version.json) 核对。

## 阶段顺序与必读细则

每行是一阶段的工作与交付检查点；不适用的阶段说明原因后跳过，不交空表。已有成果先核实后复用；更正按[依赖重算](references/workflow.md)返回受影响阶段。

若用户提供已逐分精剪的ChatCut或Pr时间线，按[已有时间线接续](references/workflow.md#已有逐分时间线接续)进入阶段1的账本与判读、阶段2的计分分析，复用已有剪辑，再按需执行阶段3–8；不从原片重新剪一遍。

| 阶段 | agent执行、产物与完成检查 | 开始前必读 |
|---|---|---|
| 1 原片判读与账本 | 识别双方，逐分看真实发球、发次及首次死球；记录得分依据、源片覆盖及源/主剪定位。发球是分内事件；已有片段先加可见P定位。交付已判读账本和剩余待办，不能只列候选局界 | [判读](references/adjudication.md)、[原片检查](references/source-inspection.md)、[账本](references/ledger-and-review.md)、[覆盖](references/coverage-and-exceptions.md)、[逐分定位](references/presentation-and-qa.md#分析期逐分定位与基础图层) |
| 2 计分、精剪与基础图层 | 推进小分/局分/盘分并核对局界，保留完整死球证据；在每分主剪实际加入计分板、显示序号和每次保留发球的短时发次标签。未知比分单独留空/待核，已知照填；不等复核或统计完成才做定位。检查编号与角标退出 | [规则](references/inputs-and-rules.md)、[异常](references/coverage-and-exceptions.md)、[剪辑与显示](references/presentation-and-qa.md) |
| 3 必要人工复核 | 先自行补查；只收剩余真疑点及计数矛盾必需的相关分。交付**可定位的独立复核时间线＋可打开的交互HTML链接**，本地模式用独立复核工作区。核对R/P、逐分短剪、常显信息和填写/保存/导出；无剩余疑点明确说明并跳过 | [复核范围与协议](references/ledger-and-review.md)、[复核布局](references/presentation-and-qa.md) |
| 4 回填与再核算 | 按P号和版本合并答案，保护确认历史；重算全部后续计分及依赖图层，给出已解决/仍未知的范围。得分确认不代替技术判读；不因所有行填过就宣称冲突解决 | [回填与逆推](references/ledger-and-review.md)、[依赖与检查点](references/workflow.md) |
| 5 技术统计与全量估速 | 从事件汇总统计，独立评估来球压力与UE终结拍动作；逐盘估算全部真实发球，含精剪删除的一发失误。交付逐发数据与统计、分母和证据覆盖；不能用抽样代替全量或直接放弃难测球 | [统计](references/statistics.md)、[UE/FE](references/error-classification.md)、[初速模型](references/serve-speed-model.md)、[估速取证与降级](references/serve-speed-audit.md) |
| 6 制作统计面板 | 将同一最终数据装入正式五页模板并加入盘末/片尾，默认每页8秒；检查五页真实合成、数字与未知覆盖，不只交数据文件 | [正式模板](references/visual-templates.md)、[片尾与盘末](references/presentation-and-qa.md) |
| 7 回填逐发球速 | 面板完成后，在已有主剪发次标签下加入该发初速；检查实际出球后才出现、最多3秒及大小标签同帧退出，不改变复核常显规则 | [球速标签时序](references/serve-speed-overlay.md) |
| 8 合成验收与交付 | 检查当前版本真实画面、声音、编号、计分边界和依赖图层；交付工程/时间线及约定成片、必要复核链接、统计与估值覆盖、剩余限制。只报告实际检查范围 | [验收](references/presentation-and-qa.md)、[检查点](references/workflow.md) |

## 全流程不能越过的边界

- 先确认真实发球、首次死球和必要的落点/对手反应；练习挥拍、放弃重抛、死球后回送不凭外形变成发次或活球；真正尝试发球却挥空算失误、耗发次，但没有离拍速度。死球不清先扩展证据，主剪和复核都不能提前截断。
- 不为吻合终场比分改球果、补造缺分或虚构完整局；缺分矛盾回查整局、被删间隙与邻接边界。唯一约束逆推、视频判读、用户判罚和现场例外分别保留依据。
- 复核逐分短剪，R在P前且同分稳定；右上常显局次、发球方和发次。独立HTML默认无视频，本地工作台集成播放器；保留“人工无法确定”列、全部复核行、草稿和滚动位置。
- 得分确认不等于技术字段全部确认；null不等于否认双误。pending/partial、人工已审未能归属、重打及多打按各自语义处理，未解决归属不能沿用旧胜者统计。
- 发次是agent判读职责：回查上一分死球至本次发球的原片，包括删去的一发；一发失误才进二发，let不耗发次。“发次待核”仅用于查过仍缺证据的个别事件，不是全场默认标签或用户逐发必答项。常规技术判读亦不转交用户。
- 初速估值、飞行均速、区间和补估分开；最高取中心值，不取上界。先核实事件，碰网分段；部分轨迹必须经过阶段5细则的几何、边界、留出预测和敏感性检查，不宣称雷达精度。
- UE/FE看对手来球压力，移动/站定独立判；第五页前两项只计UE内动作次数，保持中性。UE主数较少方高亮，未知单列；详细方法不挤进面板。
- **主剪短时角标与复核常显信息分开。** 主剪发次在发球前出现，出球后最多再留3秒，遇更早剪口/分界/下一发即退出；尚未计算球速也执行，不铺满整分。阶段7加入球速后共用退出帧；双误证实后改字，不重启计时。复核右上信息始终可见。
- 模板成功生成或脚本检查通过不等于实际合成正确；必须检查当前项目相关真实帧及声音。

## 数据与工具

选手姓名/ID、持拍手、素材和项目标识、源路径、赛制及结果都来自当前任务。A/B仅为内部映射，不能固定某方持拍手或外观；示例中的数字和编号不作为预设。只允许明确标注的匿名复杂案例，不携带真实项目媒体ID或硬编码视频路径。

[辅助材料用法](references/helper-usage.md) 列出计算、取证、复核与模板工具；它们不代替当前编辑器能力。飞行均速、全失误动作等诊断不替代初速和UE动作主行。

若本地文字损坏，按辅助材料用法先验证规范归档，必要时恢复本地副本；恢复不等于更新账户中保存的技能。用户仅要求修改技能时，只修改技能及维护文档，不启动比赛工作流，不改动项目时间线、现有HTML或审核草稿。
