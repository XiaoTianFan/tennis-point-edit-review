# 网球逐分精剪、计分与复核

用于有连续比赛画面的网球单打录像。支持六局、四局、有占先、无占先、限时不限局、纯抢七及纯抢十；采用用户已给规则和下述默认值，只有影响结果且无法从素材核实的真实缺口才追问。不是比赛裁判或雷达测速工具。双打需要额外确认发球与接发顺序，再扩展规则，不能直接套用单打核算器。

## 当前规范与调用边界

包版本 **2026.10.04-v21.2**。网球剪辑任务即使用户未手动点选本技能，也应按任务类型检索并加载；未另指定UI技能/模板/风格时，直接复用本包正式模板，禁止随机重设计。优先级为用户当前明确要求、项目已确认风格、本包默认。

用户提供原视频，可指定编辑器。agent探测可用环境、完成所需配置，按下列阶段推进；只询问无法从素材核实的关键比赛信息或必需的人工激活动作。

使用 [正式模板清单](examples/ui-manifest.json) 与 [模板说明](references/visual-templates.md)。场景、规则或画幅需要适配时保持已确认视觉语言。声明可编辑属性并在目标项目实测后才交付。主比较行与组件数量由正式清单和 [版本元数据](references/package-version.json) 核对。

各阶段先读对应细则，再执行。用户仅要求修改技能时，不改动项目时间线、现有HTML或审核草稿。

若本地文字损坏，按 [辅助材料用法](references/helper-usage.md) 先验证规范归档，必要时恢复本地副本；恢复不等于更新账户中保存的技能。

## 跨环境执行与能力补齐

本工作流不以ChatCut或某种agent为前提。先读[编辑环境选择](references/editing-environments.md)：**ChatCut、Premiere Pro、本地独立流水线是并列一级候选**，按用户指定、已有项目与实测能力分流，不默认先ChatCut或自建。编辑层与[图形层](references/graphics-adapters.md)分别选择；选Pr必读[Premiere分支](references/premiere-pro.md)，显式区分旧版CEP/ExtendScript与新版UXP。采用原生MOGRT、透明PNG/视频等格式可保留相同工作流与视觉语言，不要求所有环境执行相同JSX。

技能运行只假设终端/文件交互及可用的媒体检查能力，不要求Computer Use或鼠标点击。Pr首次安装/启用host桥可能需要用户一次性设置，之后通过终端可调用的MCP或插件协议执行；安装、连通、导入、实际合成验收分别证明。缺少当前环境工具不等于网球逻辑不可用，也不要求用户为此切换平台。

缺少执行能力时，agent应在已授权工作区自行搭建最小可用流程：例如用FFmpeg或同类工具完成逐分裁切、拼接、音画同步与导出，用逐帧工具取证，为现有JSX模板补充兼容的渲染适配。保留源时间到成片时间的映射，复用本包账本和统计工具。独立复核可交付带稳定R/P编号的逐分视频、可定位的时间记录及HTML交互列表；HTML仍无需内嵌视频，用户需能在可用播放器中找到对应片段。全部现有判读、剪口、计分、复核与合成验收要求继续适用；自行运行和检查结果，不把自建流程当作已经验证。只有具体媒体访问、执行权限或其他真实阻碍仍无法解决时才说明缺口，继续可独立完成的工作。

能力补齐仍尊重已选编辑器与交付格式；指定Pr时可先生成待导入包，但不能静默改为仅交视频。Pr默认混合图形：简洁信息优先原生可编辑，复杂统计可由正式模板渲染；逐项声明可编辑属性和待验能力，不能把栅格文字说成原生可编辑文字。

## 首次回复与任务信息

新比赛首次响应默认先简短介绍工作方式，除非用户明确表示跳过；同一比赛继续、修正及回填不重复介绍。介绍不是等待批准的门槛。信息足够便介绍后继续；缺失问题合并询问，已知内容不再问，不额外调查用户是否熟悉本技能。先读 [首次引导](references/onboarding.md) 和 [输入与规则](references/inputs-and-rules.md)。

默认从0:0第一分第一次发球开始；结束时暂按没有未完局并用尾段与计分链核验；已确认样式优先，否则采用深蓝／青柠。未知持拍手只问一次，未答暂按右手并记录假设；已知左/右手不被默认值覆盖。最终比分未知也能开始。不能把默认、推定或“presumably”写成视觉已证实，不反复确认上述默认。

## 全流程不能越过的边界

- 先确认真实发球、首次死球和必要的落点/对手反应；练习挥拍、放弃重抛、死球后回送不凭外形变成发次或活球；真正尝试发球却挥空算失误、耗发次，但没有离拍速度。死球不清先扩展证据，主剪和复核都不能提前截断。
- 不为吻合终场比分改球果、补造缺分或虚构完整局；缺分矛盾回查整局、被删间隙与邻接边界。唯一约束逆推、视频判读、用户判罚和现场例外分别保留依据。
- 复核按分精剪，不能交连续整局等待段。R在P前且同分稳定；局次、发球方、发次在复核右上常显。HTML默认无视频，保留“人工无法确定”列，所有行始终可见，保护草稿和滚动位置。
- 得分确认不等于技术字段全部确认；null不等于否认双误。pending/partial、人工已审未能归属、重打及多打按各自语义处理，未解决归属不能沿用旧胜者统计。
- 精细取证与补核由agent承担，不增设逐字段用户审核任务。先自主回查，只合并提出仍影响结果的具体问题；用户明确要求更细审核时再扩展。
- 全量估速包含精剪删除的一发失误；初速中心估值、飞行均速、敏感性区间和模型补估不得混淆。最高值不取区间上界，无依据不得编数。先核实事件时间，碰网即分段；部分轨迹须通过几何、边界、留出预测及敏感性检查，没有雷达基准不宣称实测精度。
- UE/FE先看对手来球压力，移动/站定独立判；第五页前两项只显示UE内动作次数，保持中性。UE更少的一方按已采纳主数高亮；未知仍单列，不当作已分类。详细方法不挤进面板。
- 主剪发次标签在发球前出现，球速在出球后出现，最多3秒并在更早剪口/分界退出；双误证实后改字，不重启计时，大小标签同帧退出。复核常显信息不套用此退出规则。
- 模板成功生成或脚本检查通过不等于实际合成正确；必须检查当前项目相关真实帧及声音。

## 数据与工具

选手姓名/ID、持拍手、素材和项目标识、源路径、赛制及结果都来自当前任务。A/B仅为内部映射，不能固定某方持拍手或外观；示例中的数字和编号不作为预设。只允许明确标注的匿名复杂案例，不携带真实项目媒体ID或硬编码视频路径。

[辅助材料用法](references/helper-usage.md) 列出计算、取证、复核与模板工具；它们不代替当前编辑器能力。飞行均速、全失误动作等诊断不替代初速和UE动作主行。
