# UE / FE 与 UE 终结拍动作

## 定义与适用范围
[LTA 官方术语](https://www.lta.org.uk/fan-zone/tennis-stats-explained/)把 FE 归因于对手施压或造成困难击球位置，把 UE 归因于自身执行失误，而非对手压力。本规范据此建立可复查的录像判读流程；不是声称存在一套跨赛事、跨统计供应商完全统一的客观阈值。

每分只评估失误方最后一次真实触拍，包含接发、底线、前场、截击等。ACE、对方制胜分、双误、挥空及死球回送不混入 UE / FE；本面板双误单列，避免与 UE 重复。得分方、死球方向、正反手与受迫程度分别记录，用户确认得分不等于确认 UE / FE。

## 先判来球压力，再独立判动作
1. 回看至少对手上一拍至本次首次死球的连续源片，必要时再向前追溯恢复位置；不能只看失误姿态或最后静帧。检查来球时间、速度、深度、角度、高度、追身情况及选手可用的反应空间。不得用估算球速一个阈值自动判 FE。
2. **FE：** 有可见的对手来球质量造成的明显时间或空间限制，例如大角度拉开后的低位伸展救球、深重来球压缩准备、追身来球挤压触拍、快而难处理的网前球。记录具体压力证据，不能只写“跑动”“失去平衡”或“输了”。
3. **UE：** 来球可正常处理、反应时间及空间基本充分，失误主要发生在自身选择或执行中。普通球上的启动迟、准备晚、间距处理不佳，不能因最后动作仓促就自动归 FE。主动进攻和高风险落点选择产生的失误也可为 UE；UE 不表示每次都必须打进。
4. 正在移动也可能是 UE，站定也可能是 FE。上网对手的存在、回合长短、正反手、接一发/二发、比分压力和接发失败本身均不是单独定类依据。使用同一比赛水平下合理的常规回球基准，不把一方的弱项自动免责，也不套职业选手的完成要求。
5. 同类边界球并排回查，保持双方口径一致。保留判断依据、原片定位、置信程度、旧分类及修订；扩大源片后仍无法判断则分类 unknown。不能把 unknown 默认算 UE、FE，或为凑总数强分；无需为了这一主观技术项新增整批用户审核。

## UE 内移动 / 站定计数
在完成上面的独立分类后，筛选 UE，再读取该次终结拍的动作分类；每分最多计失误方一次。只补核这些终结拍前、中、后必要画面，不扩成全场逐拍动作统计。
- moving：触球窗口仍有明显连续横向或前后位移，或在追球伸展中触球。
- stationary：已到位并形成稳定支撑；正常转体、重心转移、触球前调整步及触球后回位不自动算 moving。不能用“脚有动”作为移动标准。
- unknown：触球窗口遮挡或时序不足，补看后仍无法确认。单列未判，不塞入另一类。

默认第五页前两项为 **UE · 移动中击球**、**UE · 站定击球**，显示次数，维持中性色。移动数 + 站定数 + 动作未判数 = 已分类 UE 总数；FE 和受迫性未判失误不进入该集合。它们是 UE 的构成，不是“移动/站定的失误概率”，也不能证明脚步导致失误。用户明确要求比例时才以 UE 总数作分母，并保留次数；真正动作失误率必须另有该动作全部击球机会作为分母。

## 数据与覆盖
point.errorAssessment 保存 reviewed、classification（UE/FE/unknown）、opponentPressure（imposed/not_evidenced/unclear）、basis=incoming_ball_and_available_response、reason、confidence 和 evidence。terminalError=true 表示已知实际触拍失误；受迫性未判时 ending=OTHER，不改变 winner 或 deadBallType。shot 保留独立 terminalErrorMotion 和 motionEvidence。
未知受迫性不等于未知球果：仍计该选手总失误和已知下网/出界方向，不进 UE/FE 主数或 UE 动作分母。已知方向的分母包含所有已知触拍失误，包括受迫性未判；每类未知都保留覆盖，不能重新归一掩盖缺失。

汇总不靠旧面板数字增减。重新从事件计算 UE/FE、双方正反手拆分、UE动作计数、方向分布及相关第三拍指标，再检查终结总数守恒。误差分类不改变总得分、回合拍数或已确认局分。UE按当前已采纳主数比较，较少的一方高亮；未判仍独立保留，不计入UE且不取消UE的显示比较。相等、缺失仍不高亮，颜色不表示最终真实排序已确定。FE保持保守比较：未判足以使FE排序并列或反转时取消FE高亮。

面板只呈现名称、数值及必要的紧凑未知计数（例如“受迫性未判 1”），不加入定义、训练结论、因果解释或长段注释；方法与逐分证据留在技能及统计记录中，用户需要时再解释。
