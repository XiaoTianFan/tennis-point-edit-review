# 阶段衔接、重算与交付检查点

各项判读和显示细节见入口路由的对应模块；本页规定阶段交付和前后依赖，不新增用户审批门槛。

## 阶段记录与接续

默认每轮完成入口表中当前适用的一阶段，再向用户交付检查点并说明下一阶段；不在一次回复内默认承诺做完全场。用户明确要求连续执行时，阶段检查点改为过程汇报，逐阶段读取和自检仍保留。首次环境与信息检查并入首个实质阶段，不单独占一轮；无疑点的复核/回填直接跳过。单项修正只执行受影响的工作，不重启八阶段。

沿用项目已有工作记录；没有则保存一份简短阶段记录：当前阶段/连续或分步模式、工程与账本版本、已读细则、已检查范围、产物路径与自检结果、未完成项/具体缺口、下一步。大型阶段可按局或证据范围分批，记录实际进度；批次完成不冒称全场完成，也不为每次工具调用设置交付点。下一轮先核对当前项目与记录，再读取要执行阶段的细则；状态过期时从受影响阶段接续。

检查点用简短事实报告“本轮完成什么 → 产物在哪里、查了什么 → 仍有什么具体问题 → 下轮做什么”。确认的是工作结果，无需用户逐条签字或重复授权。只有必须由用户回答的真实规则/证据缺口或必需人工设置才提问，已授权的本阶段工作主动完成。若无法完成，写明未完成项和原因，不把只有计划、候选或全空待核表的状态称为完成。

## 执行顺序
首次引导与信息整理 → 原片逐分判读/稳定账本与可见定位 → 计分链、精剪及主剪基础图层 → 必要复核及回填 → 技术统计与全量逐发初速 → 统计面板 → 逐发球速标签 → 实际合成验收。
素材判读、计分和精剪可以逐段迭代；未解决的球果不能因进入后面阶段就自动变成确认。允许继续独立工作；最终交付把已采用现场例外、未解矛盾、技术未知与统计覆盖分别说明。

## 已有逐分时间线接续

仅适用于用户提供已逐分剪好的ChatCut或Premiere Pro工程，且当前环境可读取和编辑该工程的情况。

- 读取指定工程与序列，保存当前版本；保留用户剪口、顺序、原声及既有图层。将现有片段、源素材入出点、变速和时间线位置映射到稳定pointId；一分可含多个片段，不能把每个clip直接算作一分。已有明确确认沿用，“已剪好”本身不代表球果已确认。
- 阶段1补建或核对账本，自主判读得分方、发球方与发次，并先给现有逐分片段加可见P定位。阶段2推进小分、局分和盘分，核对每分所属局/盘及各局、各盘和整场胜负，同时制作计分板和短时发次标签；具体未知留空/待核，不能因此省略全场定位或把已知字段一并清空。只对自行回查后的剩余疑点进入阶段3–4。阶段5完成全量初速估算与技术统计，阶段6–8加入统计面板和逐发球速，再检查实际合成；不把基础图层拖到统计阶段。
- 原片用于补查被剪掉的一发失误、死球证据和计分缺口；源片不可访问或映射不全时明确覆盖范围与未知，不凭剪辑顺序补造结果，也不把变速后的时间用于原速估算。默认不重剪已完成片段；发现必要证据被截断时按剪口修复规则处理，不为统计或估速恢复已删等待段。

## 更正后的依赖
| 更正类型 | 自主回查与重算范围 |
|---|---|
| 漏分、重复分、发次误归组、合并/拆分、计分资格或采用赢家更正 | 回看相关整局和邻接边界；保护编号谱系与确认历史，重新全链进位，更新局盘、计分板、依赖统计及复核版本定位 |
| 剪口遗漏落点/下一拍/对手反应 | 先扩大原片并确认首次死球，再判断球果或逆推；回映射保留片段和所有依赖图层，不重复交付原截断证据 |
| 持拍手更正 | 保留新的确认来源；回看实际触拍侧与动作后更新相关正反手数据，不能整体机械交换标签 |
| UE/FE或动作分类更正 | 回看来球压力与独立动作窗口；从事件重新汇总UE/FE、手别、UE动作、方向及相关第三拍指标；不因此改已确认得分和局分 |
| 发球触拍、初速模型或速度估值更正 | 重新确认触拍至首次碰撞前的同球证据；更新该发与引用它的补估记录、相应盘/全场聚合、最高候选及统计面板，再同步相关球速标签与大小标签退出；不因此重写已确认球果 |
| 只更改显示风格或排版 | 更新已授权模板和实例，保留数据、剪辑定位及用户复核答案；检查受影响的真实合成帧 |

以 [覆盖与现场例外](coverage-and-exceptions.md) 记录内部取证、谱系及重算，不增加用户逐字段确认。用户确认得分只锁定对应事实，不能顺带确认未知技术字段；发现与用户确认矛盾的新证据时展示依据及影响，不静默推翻。

## 阶段检查点
- 判读交付前：账本保留实际判读依据及源/主剪定位，未查范围与查后未知分开；已有主剪逐分可见定位，片段数、候选分数和有效分数不混报。
- 计分/精剪交付前：主剪每分有计分板及可见序号，每次保留发球有按已查证据制作的短时发次标签；已知填入、未知按字段标记。无球速时也检查出球后3秒或更早边界退出，不能用撤下错误标签代替正确回填。
- 复核交付前：每分独立短剪并有充分死球证据；R/P、常显局次与发球方、发次及HTML定位同源；所有行常驻，未知列与草稿完整。
- 统计发布前：检查有效分与终结分类、分母及未知守恒；UE/FE以独立来球压力为依据；每盘真实发球清单包含精剪未保留的一发，模型补估来源可追溯。
- 面板完成后：再回填主剪逐发球速；验证出球前后、3秒或更早边界及双误状态切换；不能套用到复核常显信息。
- 最终交付前：按 [画面验收](presentation-and-qa.md) 查看当前合成画面和声音。已通过自动检查只证明被检查逻辑，不证明当前素材球果或所有分辨率的视觉表现。
