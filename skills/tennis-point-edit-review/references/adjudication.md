# 逐分判读经验

## 证据顺序
看完整上下文 → 找最后几次有效触拍 → 跟踪同一颗活球 → 找首次落点/触网/二跳 → 对照线与判罚 → 交叉核对现场口头报分和下一分。
最后谁挥拍、谁弯腰捡球、谁更接近球、谁先走向发球位置，都不能单独证明得分者。最终比分只能发现冲突，不能创造画面证据。

## 逐帧和 CV
先用较疏采样定位区间，再用原始帧率/时间戳检查事件前后的连续帧；远端、疑似压线和触网不得仅凭接触表摘要。
邻帧差分 + HSV 球色筛选 + 连通区域只生成候选。先排除运动员、拍框、亮衣服、反光与阴影；固定机位的静止旧球应作为背景排除。若机位移动，要先配准或改用原帧人工判读。
同时展示未标注原图、局部放大、相邻帧与候选；不能把处理后亮点当作球的真实接地点。记录源时间戳、帧序号、证据窗和校验过的球路。VFR 用逐帧时间戳，不能把名义帧率强当真实间隔。

## 常见易错情况
- 球打拍框/拍杆后飞向侧外：仍需跟踪出界球；不能因异常方向就漏记有效击球。
- 出界后对手帮忙碰回：分在首次出界落地时已结束，后续回送不计拍数、制胜分或新回合。
- 球先落自己一侧，再二跳弹过网：已死球；不能把最终停在哪一边当输赢依据。
- 网前/网袋附近球：检查发球前该位置是否已有静止球，以及活球是否首先碰网后回落；不能用另一颗旧球推断双误。
- 选手口袋掉球、邻场来球：跟踪各自起点，不能将第二颗球当活球落点。
- 挑高/截击制胜：确认对手是否在球二跳前触到、活球是否已出界；不要仅看选手放弃追球。
- 合法发球、接发未触球、发球方直接得分才是 ACE。接发碰球后打飞是接发失误/发球直接得分，不是 ACE。
- 一发失误→二发擦网→再发二发：let 不占用发球次数，最后仍标二发。重抛与擦网必须分别记录。
- 双误：查全两次实际失误。主剪删除一发不等于统计丢弃该证据；最后发球片段必须真实覆盖二发触拍至死球。
- 线属于界内；球体悬空投影不等于接地点。看不清首次接地、被遮挡、出画或运动模糊，写明精确缺失证据，不笼统写“远端不清”。
- 合法球绕网柱过网可仍然有效，不能因没有从网带上方经过而自动判下网。遇到特殊规则查现行规定与本场约定。

## 冲突与例外
球果、用户采用的现场判罚、规则应得结果、实际后续记分路径分别保存，禁止悄悄覆盖。
出现提前赢局后又多打一分：保留该分的实际球果，标记 extra，不记入有效分/技术统计；临时说明“前分已规则赢局、该分多打、现场随后如何记”。
若现场把局归给另一人，经用户确认后可沿现场路径显示后续比分，同时保留规则路径与例外说明；不得因此修改前面某分以“修平”账本。
若新证据要改用户已确认球果，展示证据及改动影响，不能静默推翻。用户最新明确纠正优先，旧结论留历史。

## 复核理由模板
“在 [源片时间窗]，[球/拍/线] 被 [遮挡/出画/压缩模糊]，无法确认 [首次落点在何侧/是否触拍/是否第二跳]。已检查 [相邻原帧、差分、局部放大]；候选为 [A得分理由 / B得分理由]。需确认 [一个具体问题]。”
不是所有指标都要用户确认；优先自行解决清晰球，将少量真争议、关键记分矛盾送审。


## 持拍手与未知归属
开始时先核对是否已有持拍手信息；未给的选手只询问一次“是否有左手球员／双方分别哪只手持拍”。未回答或采用默认设置时，未知选手一律暂按右手，记录 handedness=right、handednessSource=default，并继续工作，不将等待答复作为门槛。已明确为左手或右手的选手沿用已知信息，不重复询问、不被默认值覆盖。后续明确更正时，按真实持拍手重核相关正反手与统计，不机械交换全部标签。 正反手以持拍手和真实触拍动作判定，不按画面左右套标签。默认右手只是假设，不能写成已视觉证实。人工仍无法判定得分时使用独立待逆推标记；按账本与复核协议检查全部约束，规则推定不得改写为看清了首次死球。


## 球仍可能在打时不能提前结束观察
死球尚未确认时，一律按可能仍为活球继续保留，沿源片向后检查并纳入下一拍、球的落点及对手的后续反应；若仍有回球，继续延伸直到明确首次死球或双方进入非比赛状态。禁止在球刚飞起、刚落地、对手尚未作出反应时截断，也不得按固定秒数或未经证实的最后一拍猜剪口。仅在死球已证实后才删除捡球和准备，不能把证据必要的后续反应误删成等待。 发球接收者未触到球时，不得标为该接发者回球下网；先判断发球是否入区、是否一发失误/双误/ACE。碰回已出界发球、赛后轻送球不能当有效触拍。每个技术标签须对应可定位的真实动作；终局约束只能推断得分方，不能创造触拍、落点或死球类型。


## 空挥、抛球接回与真正发球
- 候选动作不等于真实发球或击球。检查同一颗球的起点、球拍与球接触及接触后的球路；活动身体、空挥、练习挥拍没有实际发球触球证据，不得登记为一发失误、有效触拍或独立得分。
- 抛球后主动放弃且未尝试击球、接回或任球落地后重抛，记为非发球准备事件，不消耗当前发球机会；不能因为有举臂、抛球或引拍动作就认定已完成一发。真正尝试击球却挥空与主动放弃重抛必须分开，不能一律按重抛处理。
- 标二发前须定位本分真实一发失误的证据；查不到时发次保持待核，不能用前一段空挥或接回抛球补作一发。回查上一有效分结束至本次发球的完整间隙，真实一发可能早于错误候选动作，也可能本次才是首次实际发球。
- 主剪去除无关空挥与抛球接回。只有用于解释发次错误时，才在复核片段内紧凑保留，明确标“空挥／抛球接回 · 不计发次”；随后实际发球仍显示正确发次。同一分保持同一 R/P。
- 不以没有看到新增回合直接断言现场判错。完整回查局界、删去间隙、真实触拍、有效分归组与已确认球果；分别记录漏剪候选、误合并、球果不清、现场判罚/记分可能异常及各自证据。采样未发现额外回合只能表述为在已检查范围未找到，不能伪称已逐帧证明不存在。

规则尚未完局却现场判局时，按 [未完局例外](coverage-and-exceptions.md) 保存空规则赢家、实际小分和采用的现场归属，不补造决定分。

## 真实发球与死球执行要点

2. **逐分观察，再精查死球。** 先浏览完整回合，识别双方与真实发球触拍，先排除空挥、活动身体、抛球接回及未尝试击球的重抛，不能按动作外形增加发次或拍数；再在触拍、过网、首次落点和可能二跳附近逐帧检查。用帧差、颜色候选和局部裁切辅助定位，必须回看原图；详见 [判读经验](adjudication.md)。影像不足才送用户复核，不把常见清晰球批量推给用户。

## 收到尾段不足反馈时的处理

死球尚未确认时，一律按可能仍为活球继续保留，沿源片向后检查并纳入下一拍、球的落点及对手的后续反应；若仍有回球，继续延伸直到明确首次死球或双方进入非比赛状态。禁止在球刚飞起、刚落地、对手尚未作出反应时截断，也不得按固定秒数或未经证实的最后一拍猜剪口。仅在死球已证实后才删除捡球和准备，不能把证据必要的后续反应误删成等待。 收到剪口不足的反馈，先扩展源片证据再判读或逆推；不能直接重复原短片或只凭总分补结论。主剪和复核片段都要检查最后可见击球后的落点与对手反应；统计更新必须以真正触拍为前提。
