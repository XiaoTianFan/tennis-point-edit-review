# 技术统计口径

默认五页、39个主比较行；正反手拆分和回合分布嵌入原行，不为增加项目数制造重复指标。用户指定范围优先。数值来自同一盘/全场的逐分及触拍事件，不把缺录像的表现补为0；百分比同时显示分子/分母，零机会显示不适用。

## 1. 总览与关键分（7行）
最终局分、总得分、发球分赢分率、保发局/发球局、破发局/接发局、破发点挽救率、破发点兑现率。
破发点是接发者若赢下一分便按规则赢局的分前状态，包含无占先40–40金球；抢七/抢十不计普通局破发点。现场提前判局归属与规则小分路径分开：局类指标依明确采用的现场归属，分级压力统计依规则小分，不编一个缺失分让两者强行相等。

## 2. 发球与第三拍（11行）
ACE、双误、一发进球率、二发进球率、一发得分率、二发得分率、第三拍后赢分率、第三拍直接失误、最高发球初速估值、一发平均初速估值、二发平均初速估值。最高初速为主统计行；整体均速保留底层，不占主行。不增加中位数/P90。
一发进球率=有效一发分/发球分；二发进球率=有效二发/二发机会（包含双误）。一发得分率以有效一发为分母；二发得分率以二发机会为分母，包含双误。let不增加机会数，正常抛球接回、练习挥拍不算失误；真正尝试发球却挥空算失误，二发挥空算双误，但不进入速度分母。
第三拍指发球、有效接发之后发球方第一次实际触拍。第三拍后赢分率=最终赢下的此类分/实际打到第三拍的分，含第三拍失误；这是条件赢分率，不是全部发球分赢分率，也不能宣称为第三拍本身的因果贡献。第三拍直接失误只计该次触拍直接导致的UE或FE。ACE、接发直接失误或接发制胜而未触第三拍均不进入此分母；挥空不算触拍。
发球直得、合法发球未回发等仍可从事件推导，但默认不与对手有效接发率作为反向副本重复陈列。历史发球直得率若以全部发球分为分母，因含双误，与合法接发率并非直接互补，不能混淆。

## 3. 接发（6行）
有效接发率、一发有效接发率、二发有效接发率、接一发得分率、接二发得分率、接发制胜分。
有效接发率以对手合法发球为分母，含ACE、不含双误；接二发得分率包含双误。接发制胜分是合法接发直接制胜，不包括对方第三拍失误。省略接发深度、落点分布和主观中和等级，避免低价值细分和用户核查负担。

## 4. 回合与击球结果（8行）
三行拍长赢分率（1–4、5–8、9+）分别在副文本显示全场出现比例；三行W/UE/FE保留总数，并在双方副文本拆成正手/反手；两行显示失误下网/出界占比及次数。方向只分net/out，不再细分出底线和出边线。
发球为第1拍，终结失误的真实触拍计入；双误为0拍并单列，不进入三档分布和赢分率的分母。ACE属1拍。三档频数之和=非双误有效分；加0拍双误后=全部有效分。每档双方赢分之和=该档分数，分布频率与赢分率不可混用。若存在罚分或未见完整回合，另列范围，不强塞三档。
W不含ACE；双误不重复计UE/FE。UE/FE依[来球压力判读标准](error-classification.md)独立评估；先回看来球及可用反应空间，再另判移动状态，不以移动、站定、接发失败或失衡本身定类。双误单列。正反手按持拍手与身体触拍侧回核；不能直接套用旧文本，也不能按画面左右或击球方向机械判断。高压等不适合二分的动作可留other；遮挡保留unknown并显示覆盖，不能捏造或丢掉总数。W的手别属于得分方终结拍；UE/FE及失误方向属于失误方。终结类型未知不应由比分逆推自动补造。
失误方向分母为该选手所有实际触拍的终结失误（UE、FE及受迫性未判失误），双误排除；若方向不可见须保留unknown，不能将已知下网/出界重新归一成100%掩盖缺失。净胜分、迫使对手FE、获得对手UE等反向或组合统计不另列默认主行。

## 5. 击球位置与上网（7行）
先列 UE · 移动中击球、UE · 站定击球（次数），再列底线后深区击球占比、底线附近击球占比、场内击球占比、上网次数、网前得分率。明确不增加三个区域各自的赢分率或进攻转化率。
位置仅统计非发球实际触拍，按选手所在端：底线后超过2m为深区，线后2m至线内1m为附近，更靠网为场内。分母为可判触拍并保留未知覆盖，不混成分数。上网每分每人最多一次：活球期间主动进入约发球线以内参与网前攻防，不计死球后捡球。

## 事件模型与工作量
point表保存稳定pointId、盘局、发球方、采用胜者、规则比分、现场例外、终结类型、有效性及证据；shot表保存实际触拍序号、击球者、阶段、手别、位置、终结与源片证据；真实发球尝试另表保存发次与初速模型。源时间未知可空，并保留可定位片段证据；不能伪造每拍坐标和时间戳。
所有面板数值是这些事件的派生结果。复用已经核验的记录，代理只补看新增字段或矛盾所需片段；不能要求用户逐项确认技术分类。旧拍长可以导入已有已复核的触拍序列，未复核的数量不能单靠奇偶交替“制造”shot表。空挥、接回抛球、let、死球回送不进入有效回合触拍序列；真实发球挥空仍保留为发球失误/双误，let 另存分内事件。

## 全盘逐发初速估算
先按 setNumber、serverId、pointId、serveId、serveNumber 建立每一盘所有真实发球的清单；只有一盘也覆盖该盘全部发球。多盘分别汇总，并从逐发数值重新汇总全场，不能把各盘均值或一发/二发均值简单平均。检查原片中被主剪删掉的一发失误，不能只分析精剪保留的有效发球。默认全发球口径含失误；let、空挥、抛球接回不进入速度均值，另留排除记录；用户指定仅有效发球时按其口径统一过滤，明确分母。

目标量统一为触拍离弦后的初速估值。先检查触拍、飞行、过网、首次落地或触网的连续源帧，VFR使用源PTS。逐项目标定球场、相机、发球端和高度；地面单应不能直接作用于空中球。每发保留观测量、假设、方法、来源时刻、误差、置信等级与排除/补估原因。按[估速取证](serve-speed-audit.md)核实时间夹逼与首次碰撞；部分轨迹未通过质量检查不能进入独立证据样本，同组补估不得循环使用补估数据。

按证据选择方法：
1. 近触拍连续球位置清晰且具备足够三维约束时，从短段轨迹估计初速；像素速度本身不是实际球速。先确认追踪目标确为球，排除球拍、身体及衣服；不要把抛球或落地后的轨迹纳入出拍段。
2. 触拍到首次落地/触网的距离与时间较清楚时，先计算端点距离/时间作为飞行均速近似，再用有依据的运动模型反推初速。恒定减速度仅为明确声明的近似；距离与时间本身不能同时唯一确定初速和减速度。优先考虑重力、随速度平方变化的阻力；旋转、球况、空气密度不清楚时作为假设与敏感性范围，不伪称实测。
3. 只有部分飞行可见时，用投影轨迹与物理模型拟合，并检查回投影、触拍时刻、初始高度和终点条件；小像素残差不等于初速正确。应与独立可判的触拍/落点计时核对，不能用同一组输入做循环验证。
4. 多方法先统一到初速，再选择证据较强且偏差较小者；只有独立误差来源才做有说明的加权融合。不能把同一镜头导出的均速和初速视为独立样本重复计票。
5. 用户要求全量估算时，不因单发难测就直接留空或丢出分母：先扩大源证据、尝试其他物理约束。仍不可辨的个别发球，可用本盘同一选手、同一发次、相近条件的有证据发球建立模型补估，明确 method=model_imputed、支持样本、假设及更宽不确定性；不得称为该发的视觉测量。没有任何可支持的同组数据或约束时不能编数字，要明确具体缺口。全量包含补估时，面板保留“初速模型估算”标识；全量范围、补估数量、支持样本及假设在可追溯统计记录中完整列明，不再追加面板解释小字，不能伪称全量实测。

每发采用一个中心估值进入池中，每发等权求一发、二发与整体平均；置信度只用于该发方法选择或推断，不把清楚的快球在比赛均值中多算。最高速度取逐发中心估值最大者并保留对应发球，不取不确定区间上界。若名次区间重叠，称“中心估值最高”，不宣称确定是实际最快。

统计记录中的覆盖 a/b 明确写成“可观测/本口径总发球”，同时列模型重建与同组补估数；它不是进球率或速度范围。区间表示输入/模型变化下的敏感性，不是已观察到的最低/最高速度，也不是“无证据的区间”；未校准时不称95%置信区间。共同标定误差不随样本数增加而自动除以根号N。展示约值并合理取整，不用上界给最快值增速。

物理依据与实现细节见 [初速估算方法](serve-speed-model.md)，数值助手见 scripts/launch_speed.py。旧 scripts/serve_speed.py 仅输出几何飞行均速诊断量，不再作为主面板初速直接使用。

## 完成标准
代理主动补全统计，不因计算繁琐留下大量“待核”。有依据的AI主观分类及估值可以显示，底部统一“数据统计为 AI 生成，可能有误差”；速度保留“初速模型估算”标识；全量范围、补估覆盖及必要假设保存在可追溯统计报告中，不再挤入发球页额外小字。
真缺失时写“不适用/无可测样本/可见样本统计”并解释覆盖，不能为了“所有指标都有数”编造。
一般检查：双方总分之和=有效分数；服务/接发分母互相对应；ACE+双误+非ACE制胜+UE+FE+其他终结=有效分数（仅在互斥分类完成时）；拍长三档之和+另列的0拍双误及其他例外=有效分；位置分母=可判非发球触拍。
末局未完通常不增加已完成局数。是否把其中有效分纳入全场分级统计须按当前比赛约定。


## 持拍手及待逆推样本
开始时询问尚未提供的持拍手；未答默认右手并注明 default。已确认手别优先，换边不改变手别。后续更正须按动作重核正反手，不能机械互换所有标签。winnerUndetermined 的分在归属解决前不得带着旧胜者计入得分率、制胜分归属等依赖结果的统计；保留可独立证实的事实与覆盖说明。唯一约束逆推的结果单列来源，不自动补造死球类型、击球手或受迫程度。

## 发球直得与有效接发的逐分证据
- 发球直得含ACE、未碰到的合法发球和碰到但未合法回场的接发失误；不包含发球方第三拍进攻或后续回合赢分。默认分母为全部发球分（含双误），保留原始分母说明，默认不占主面板行。若用户指定合法发球分母，则统一改名/注明，不能混算。
- 有效接发率=合法回入对方场内的接发数/对方合法发球数。ACE在分母内且不进分子；一发失误、双误、let和未击球抛球不进入分母。一发/二发有效接发率分别使用该类合法发球分母。合法回场后输掉该分仍算接发进球；出界后对手继续回送的死球不算进场。
- 接发直得在本模板明确采用“接发制胜分次数”：合法接发直接制胜；与非ACE制胜分可有包含关系，不是互斥终结分类的新一项。对手双误、发球方第三拍失误、后续赢分不属于该指标。若用户想统计造成第三拍失误的接发，应另定义扩大口径，不能默默混入。
- agent逐点记录serveReturn.reviewed、serveIn、returnOutcome（in/error/ace/not_applicable）、returnWinner与源帧证据。已确认球果与原片联合判断；不得仅由shots==2、最终winner或旧UE/FE自动填值，完整接发是否落界内及第一次死球要视觉确认。非双误的罚分、缺画面等例外须另定义范围，不能强装成合法发球。
- 新指标未完成观察时保留缺失覆盖，先由agent扩大原片自行补核。汇总器不会把缺失当0，正式模板拒绝未完成数据；只对仍影响结果的真正矛盾向用户提问，不增加技术统计审核表。
- 全量自检：一发/二发合法接发分母之和=全部合法接发分母；双方合法接发分母与对方发球分减双误对应（仅适用于无其他特殊终结的明确口径）；接发进球+发球直得=合法发球数；分子不大于分母；0机会显示不适用。按实际逐分数重新汇总跨盘比例，不平均各盘百分比。

术语依据：[ITF术语表](https://www.itftennis.com/en/about-us/organisation/tennis-glossary/)用于ACE的合法未触球定义；[ATP Serve Effectiveness](https://www.atptour.com/en/news/insights-serve-effectiveness)还包含发球后的第一拍进攻，因此不可将本模板“发球直得率”冒称为ATP该指标。本技能采用的接发分母与接发直得范围为明确写出的工作流口径。



## UE 终结拍动作计数
第五页首两行只显示该选手 UE 终结拍中移动/站定击球的次数，详细判断和未知处理见[UE/FE判读标准](error-classification.md)。先独立判断对手来球压力，后判断动作；FE、ACE、对方winner、双误及受迫性未判失误不进入这两项。移动数+站定数+动作未判数=UE总数，不是动作失误率，不做优劣高亮。只补核必要的来球和终结触拍，不要求用户逐字段确认，也不标注整场所有动作。
面板以统计值为主，默认不增加上述定义、训练建议或因果解释。仅真实缺失时保留一条紧凑未判计数。

## 指标比较及主题色
每个主行声明comparison=higher/lower/neutral，由原始值派生highlight=A/B/null，主题色只作用于较优方主值；标签、分母说明、拍长频率和正反手拆分副文本维持中性颜色。
- higher：局分、总得分、得分率、进球/有效接发率、保发/破发率、破发点挽救/兑现率、ACE、制胜分、网前得分率；最高及一/二发平均初速按速度数值较高方标注，仅表示更快，不代表发球综合质量或雷达测量精度。
- lower：双误、第三拍直接失误、UE、FE的发生次数。只是本场该项数值比较，不推断相同击球机会下的失误概率。
- neutral：UE移动/站定次数、下网/出界构成、三个击球区域占比、上网次数及拍长出现频率。这些描述风格、机会或失误组成，无单调优劣。
比率按未四舍五入的分子/分母比较，计数按原数比较，不从展示字符串提取百分比；相等、零分母/缺失、或展示精度下完全相同的值不高亮。保留分子分母，小样本高亮不等于显著性或稳定能力结论。新增指标必须先定义比较方向，不套“数字大即更好”。


受迫性未判可通过OTHER与terminalError=true单列，仍保留球果和方向，不计入已采纳UE/FE主数。UE按当前已采纳次数比较，较少者高亮；未判数量不取消这一显示比较，相等或缺失仍不高亮。该颜色仅比较已显示统计，不表示未知最终归类后排序必然不变。FE沿用保守边界：若受迫性未判足以使FE排序并列或反转，则不标FE较优方。

## 统计与估速执行要点

7. **统计与估速。** 逐盘覆盖每位选手的所有真实发球（包括主剪删除的一发失误），每发采用统一口径的初速中心估值，依证据选择近触拍估计、带阻力的飞行反推或明确标注的同组模型补估；不得用区间上界冒充最快值，也不得把少量成功测量代替全盘。 全面计算附件指标，逐一核查每分的发球合法性、接发是否进场以及是否为接发制胜分，分别统计发球直得率和接发进球率，不用最终得分方或第三拍失误替代接发结果；复查所有合法发球的 ACE，而不把用户指出的若干 ACE 当作完整清单。代理自行判读拍数、受迫程度、网前和站位；UE/FE依对手来球造成的压力独立判定，不从移动或站定姿态直接归类。按 [统计口径](statistics.md) 输出分母、证据、样本覆盖和估算方法。不可用免责声明掩盖编造。

## 页面范围与内部补核职责

默认按总览与关键分、发球与第三拍、接发、回合与击球结果、击球位置与上网排列；使用[诊断汇总器](../scripts/diagnostic_stats.py)及更新后的[统计口径](statistics.md)。新增观察由代理承担，不生成逐字段用户审核任务。省略接发深度分布、三个位置的赢分率、重复反向指标；失误方向仅下网/出界。正反手必须回看实际动作，不能复制旧描述或随换边机械互换。
