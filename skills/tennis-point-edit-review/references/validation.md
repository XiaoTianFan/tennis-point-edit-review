## v21 当前验证与未通过的门槛

- 130项技能回归、15项仓库检查、6项Node适配器检查通过；XML新增混用mono/stereo声道槽拒收，并核对Windows路径和Stereo分组。七个正式JSX源码保持。
- 实际连接Pr 23.5.0 build 56 + CEP候选1.2.8。首次设置需先打开空工程，再启用面板；此后导入、属性、导出、保存及项目重开均走终端。关闭最后工程导致桥卸载时，客户端错误不等于关闭失败。项目重开及Pr进程完整退出/终端重启后，桥均自行恢复。
- 合成片90帧：剪口/source in/out精确tick读回和XML往返通过；90帧逐一与源片/alpha图层比较，最大全帧RGB平均绝对误差1.34/255。Stereo XML分组保留左440 Hz/右880 Hz，修复普通mono拆轨居中混合问题。中文、空格、`#`、`%`路径实机导入在线；UNC/macOS、其他帧率仅离线结构检查。
- 真实转移夹具为两分423帧，加五页各240帧统计，共1623帧/54.1秒。PNG分数、发次、球速及双误边界检查匹配计划；五页Pr原生透明度关键帧读回通过。在SDR参照下关闭线性色彩合成后，40个统计边界/稳定帧最大全帧平均误差1.60/255。对比给定参考成片的同时间帧，画面状态、布局、显示值一致，文字栅格化存在差别。
- PCM导出保留两点原声内部样本、声道与原增益，实测零样本偏移，统计尾段静音；两帧音量包络已写入读回。H.264/AAC预设有1024个48 kHz样本（21.33 ms）编码延迟。没有主观监听结论，不能说接点听感已经验收。
- Save As必须使用Pr原生`File.fsName`路径；修正后保存、关闭、终端重开及统计效果读回通过。候选导帧可能返回错误但稍后写出PNG；独立核对文件，不只相信布尔响应。
- **Native混合图形尚未验收**：Pr自带Basic Title导入成功，但此host的legacy DOM未暴露MGT文本参数。AE创作脚本和随附AE模板导入都遇到本机语言/订阅错误，未生成本包MOGRT。保留安装问题并交用户处理；真实测试的栅格标签不冒充native文字。新版UXP、整场迁移、后续修正/复核案例及主观听感仍待验。
