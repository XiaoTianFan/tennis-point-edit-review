# 正式默认视觉模板

以examples/ui-manifest.json为组件清单，读取各组件的代码、可编辑属性、自然尺寸、1080p放置比例和版本。

跨编辑器的原生/MOGRT与透明媒体实现见[图形适配](graphics-adapters.md)。七个canonical JSX保持视觉真值；原生适配不必执行相同代码，但必须保留视觉语言、字段与时序并独立验证可编辑性。模板生成、host导入与实际合成是不同验收。
网球任务未另指定UI技能/风格时直接加载本包，不随机重新设计；用户明确要求或已确认的项目风格优先。检索描述用于帮助agent找到技能，不宣称平台全局自动安装或强制加载。首次用于新片仍核对画幅、长姓名、分数字数与球员遮挡，自行验证，无须重复风格审批。

## 组件与默认比例
参考画布1920×1080，其他分辨率等比映射边距/字号；非16:9先按内容重新排布，保持颜色、分列与字阶。
- scoreboard：左下440×132，距左右/底部安全边约48；选手、发球点、局分、小分，标题容纳赛制与P号。每次状态来自同一计分链，在死球后更新。多盘/抢分须扩展字段，不将单盘示例误充完整规则。
- serveLabel：主剪右上200×54，紧凑单行一发/二发/二发·双误等内容；发球前先显示发次，双误只在失误确证后切换；与serveSpeed共用结束帧，无重复入场。
- serveSpeed：主剪右上标签正下方200×42，默认左1672、上102；与上方标签等宽，15号估值标识、24号数字、16号km/h，深蓝背景与青柠数字。独立实例只在出球后放置，最多3秒，默认静态出现/退出，并与上方大标签同时退出；补估使用明确文字。
- reviewLabel：复核右上740×62，常显局次、圆点发球符号、选手与当前发次。phaseLabel可含盘次；符号用CSS圆点，不依赖图标字体。保持发球标签视觉语言，同时提供复核所需的信息密度。
- reviewId：复核左上270×58，R在前P在后；同一分跨剪口保持连续，无入场闪烁。
- explanation：自然980×132，默认显示宽784；小标题25、正文21的自然字号、底部20内边距。长文自动建议增高，最多保留必要事实并实测，不靠裁切缩进。主剪左上；复核左下避让计分板，不能遮住左上编号或右上常显信息。
- statsPanel：自然1600×900，居中显示1440×810；五页7/11/6/8/7行，回合分布及正反手拆分作为原行副文本；11行页面仍须保留底部内边距及免责声明。数据行来自stats-pages.json，同一组件每页独立实例，按当前fps统一配置8秒及短淡入淡出。

## 可直接复用的装配
scripts/template_pack.py读取清单并输出代码、属性与布局建议；仅生成本地数据，不调用编辑器。内容与配色通过声明属性更换，不能把旧比赛的结果作为默认。
script的build_stats_pages(metrics,speedSummary,diagnostics)统一新初速字段，拒绝用旧几何飞行均速替代。调用者选择正确的盘/全场统计范围，空分母显示不适用，尚无依据的值不冒充0。发球页只保留必要口径和AI/初速估算说明；全量数量、轨迹/端点数、补估数保存在底层报告，不增加被用户删除的解释小字。
目标编辑器导入时遵循当前动效能力；本清单不是写死工具参数。跨项目复制源代码不等于已生成可见资产。每个新项目检查真实合成画面、名字/数值完整、底注不贴边以及正常/金球/局界/同分一二发转换。

## 同步与验收
检查7组件、5统计页、最长实际文案及过渡首尾；这不是要求用户逐页确认。复核HTML保持简洁与行常驻，agent内部细化不增加用户必填。

行支持sub（指标说明）、asub/bsub（双方拆分），保持三列对比。默认不额外列出发球直得率、整体平均初速或对手失误的反向副本；最高初速保留为发球页主行。仍保留完整底层统计。五页共39个主行，不用扩成大量细分行。


行另支持comparison与highlight，后者由stat_comparison.py根据原始数据产生；JSX仅渲染，不能凭格式化字符串自行比较。主题强调色使用现有accent属性，不引入第三种获胜色。副文本不随主值继承高亮；移动/站定、位置/方向占比、上网次数等保持中性。第五页首两行固定为 ueMoving / ueStationary，标签 UE · 移动中击球 / UE · 站定击球，显示次数且保持中性；从已独立判为 UE 的终结拍动作派生。面板不增加方法论或训练解释，相关内容保存在统计记录中。

UE主值采用当前已采纳次数，较少者高亮；未知独立保留，不能合入UE或视为已解决。并列、缺失及中性项目仍不高亮。FE未知比较边界见[统计口径](statistics.md)。
