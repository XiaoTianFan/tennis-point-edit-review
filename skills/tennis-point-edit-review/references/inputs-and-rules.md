# 输入、默认与规则

## 首次调用：简短引导后使用默认值并核实真实缺口

先执行[首次引导](onboarding.md)：未明确跳过时简短介绍，然后继续；不等待流程批准，不重复同场引导。
默认从0:0、第一局第一分的第一次发球开始；结束时暂按没有未完成局；样式沿用项目已确认方案，否则直接使用深蓝／青柠紧凑样式。用户没有另行要求时，不主动追问这三项，也不在可见样例后等待重复确认。默认值是工作假设，用户明确说明优先；只有与素材或计分链存在已回查仍无法解决的具体矛盾时，才针对影响结果的问题询问。
- 录像和是否有中断、漏拍、多机位；原声可用于报分辅助，但不能幻听。
- 两位选手 ID 与稳定视觉特征，初始近远端。换边后仍按身份识别，不按画面左右固定姓名。
- 开始时先核对是否已有持拍手信息；未给的选手只询问一次“是否有左手球员／双方分别哪只手持拍”。未回答或采用默认设置时，未知选手一律暂按右手，记录 handedness=right、handednessSource=default，并继续工作，不将等待答复作为门槛。已明确为左手或右手的选手沿用已知信息，不重复询问、不被默认值覆盖。后续明确更正时，按真实持拍手重核相关正反手与统计，不机械交换全部标签。
- 赛制：六局有占先；六局无占先金球；四局有占先；四局无占先金球；限时不限局无占先；纯抢七；纯抢十。
- 六局明确是在 6–6 还是约定 5–5 抢七；四局明确是 4–4 还是 3–3。5–5 等本地约定不能假装是普遍规则。
- 从用户说明或素材核实一共几盘/几盘几胜、决胜盘是否另用抢十、抢分目标与净胜规则及有无封顶；仅在确实影响计分且无法核实的参数仍缺失时追问。限时赛默认结束时没有未完局，不预先追问假想未完局如何计入；只有尾段实际发现未完局且其处理影响结果时才确认。
- 默认开场局分与小分均为0:0，从第一分第一次发球开始；从画面识别首位发球者。仅当用户说明或素材表明中途开录时，核实已有盘分、局分、小分及当前发球方；若在抢七中途，还需该抢七首位发球者或足以还原轮换的信息。
- 终场结果及可信来源；未知也可开始。用户给出 7:2 等需区分局分、盘分还是抢分数字。
- 默认影片末尾即比赛结束，暂按没有未完局继续分析。若用户明确说明练习则分开；若核算显示尚未完局，回查尾段并保留未完局可能，不为满足默认值擅自补分、强行完局或判成练习。用户表示“应该没有／presumably”时保留其不确定程度。
- 统计附件；没有新附件则采用本技能[正式统计清单](../examples/stats-pages.json)定义的五页比较指标（含二发进球率、第三拍表现；回合占比及正反手拆分嵌入原行）。逐盘建立全部真实发球清单，明确是否含失误及模型补估。若素材并非全场，明确“录像覆盖范围”，不把缺失场外部分统计成 0。
- 计分板沿用当前项目已确认风格，否则直接采用附带深蓝/青柠紧凑样式。样例用于检查实际合成效果，不是必须等待用户批准的步骤；用户未要求更换或比较样式时，检查后继续批量制作。

## 规则核验
有占先普通局按净胜两分结束；无占先 40–40 下一分直接结束。纯抢七/十使用整数小分与约定目标，不能伪装成普通局、盘分。普通抢七的 1 分后双方各连续发 2 分；下一盘第一局由该抢七首位发球者的对方发球。发球擦网且落在正确发球区才是 let；擦网后出界仍是失误。未击球的正常抛球重抛不算一次发球失误。单双打、短盘、特殊联赛规则有差异，按约定确认。

常规换边与发球轮换只作边界校验。抢七中换发球不是换局；赛中饮水或长停顿也不证明换局。有缺失画面时不能强行让轮换连续。

已完成的规则局，其最后一个有效得分者就是规则赢家；此结论不适用于未完局、额外多打、整分重打、非计分喂球或已确认的现场记分错误。先确认“最后有效分”及是否满足完局条件，再用末分核查归属。

## 应用工作假设与已有上下文

开始时先核对是否已有持拍手信息；未给的选手只询问一次“是否有左手球员／双方分别哪只手持拍”。未回答或采用默认设置时，未知选手一律暂按右手，记录 handedness=right、handednessSource=default，并继续工作，不将等待答复作为门槛。已明确为左手或右手的选手沿用已知信息，不重复询问、不被默认值覆盖。后续明确更正时，按真实持拍手重核相关正反手与统计，不机械交换全部标签。

先检查用户已给的录像、附件、选手描述、规则与当前剪辑。按 [输入与规则](inputs-and-rules.md) 整理赛制、选手身份与发球顺序、已知终场及统计范围。最终比分可以未知，不因此停止分析。

除非用户另有要求，直接采用以下默认值并继续工作，不弹出例行确认表，也不在样例完成后等待批准：
- **开场：** 录像从比赛0:0、第一局第一分的第一次发球开始；普通局初始小分为0:0。首位发球者从画面识别，不凭姓名顺序猜测。
- **结束：** 暂按比赛结束时没有未完成局处理。此为工作假设，需在尾段和计分链核验；不能将“应该没有／presumably”写成已核实事实，也不预先要求用户选择假想未完局的处理规则。
- **样式：** 沿用当前项目已确认的计分板风格；没有已确认风格时直接采用本技能的深蓝／青柠紧凑样式。可生成样例并自行检查，但不将重复批准作为继续制作的门槛。

用户明确说明优先于默认值。若原片或计分链出现具体矛盾，先自行回看相关证据；仅对仍无法解决且会改变结果的问题定向追问，并说明矛盾。默认录像末尾是比赛结束，不擅自标记赛后练习，不补造缺失分，也不从终场比分反推缺失规则。其他未给且确实必要的赛制参数按输入与规则处理；不能因这三项未被逐一回答而暂停。
