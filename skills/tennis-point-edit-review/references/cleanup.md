# 成片导出后的收尾清理

每次剪辑任务结束、用户的最终成片已成功导出后，由agent主动准备本片清理方案并询问是否执行。适用于三种编辑环境；素材、工程和临时产物的路径均从当前任务读取。

## 导出核实与用户确认

- 核实实际输出文件、导出成功记录与工程版本，确认这是任务最终成片。点击导出、打开导出框、预览片或中途选段导出本身不代表剪辑结束；导出失败或仍在编码时不进入收尾清理。
- 先盘点并按下节备好可复核的保留／删除清单，列出本片可删临时产物的具体目录／类别、预计大小，以及原录像、最终成片、统计和可重开工程的保留位置，再询问：“成片已导出。是否清理上述本片临时产物？原录像、最终成片、统计数据、可重开的工程及其依赖和skill包会保留，并在清理后核验完整性。”
- **未收到明确确认不执行清理。** “剪辑已完成”、允许连续执行、同意导出或等待超时均不代替清理确认；用户拒绝或未答则保持文件。用户已明确要求清理本片时可直接按该授权执行，不重复询问；另一场比赛的清理授权不沿用。
- 导出器正常回收当次渲染临时文件的既有行为见[本地导出](local-editor.md#导出与边界)，不代表任务工作区已清理，也不扩大为删除旧导出或其他产物的授权。

## 清单与保留范围

询问前读取当前工程、导出记录、账本、答案和统计版本，按实际引用关系建立保留／删除清单。清单记录解析后的绝对路径、大小、删除理由与修改时间；受保护文件另记录SHA-256，一并保存到本片工作区的小型清理记录目录。得到确认、执行前再核对当前状态；遇到文件变化或新增引用，先更新保护范围并收缩待删项，超出已确认范围的删除须重新说明并获确认。不能用旧计划覆盖当前工程。

始终保留：

- 原录像、用户原始输入和采用的最终成片，以及对应导出记录和工程快照。
- 最终逐分账本、计分链、稳定P/R与源时间映射、用户答案及采用历史、技术统计、逐发估速结果和必要的PTS、标定、模型参数与证据索引，保证数据可追溯。不能只留下烧录在视频中的统计面板。
- 可重开的当前工程及其依赖：仍被工程、内置Undo/Redo或恢复状态引用的媒体代理、音频、图层、图片、模板实例和必要运行依赖；保留必要的恢复记录。代理、缓存名或“临时”目录名不构成可删依据。
- 全部skill包内容，包括脚本、参考资料、七个正式JSX模板、示例、版本元数据与恢复归档；共享工具、运行环境及其他比赛的文件不进入本片清理范围。

可删项限于本片生成且不在保留依赖内的抽帧／裁剪／拼图缓存、可重建预览缓存、重复或过时的临时编码与预览片、废弃计划和外部快照、不再引用的旧图层、一次性分析／辅助脚本。仍承担唯一证据或恢复作用的文件继续保留；不能只按扩展名、文件年龄或目录名批量删。

## 执行与完整性核验

1. 核对用户确认、清单及受保护文件哈希，确认无编码、未保存编辑或写入任务；如需停服，核对进程命令行和工程路径，仅停止本片临时进程，不停止共享服务。
2. 删除前逐项核对绝对路径在本片授权工作区内、未命中保留清单、大小和修改时间未变；拒绝符号链接、junction和其他reparse point及其穿越路径。Windows使用原生PowerShell的显式`-LiteralPath`文件列表，分批执行；不递归删除整个工作区，不跨shell拼接删除命令。仅移除核实为空的目录。
3. 清理后确认所有已执行删除项确实消失，受保护文件全部存在且大小／SHA-256一致，skill包完整未改。核对最终成片可读及画幅、帧数／时长、音轨信息；以只读加载与依赖检查或实际重开验证工程、媒体和图层可用，版本、剪口、P/R、答案及统计保持一致。验证生成的缓存计入清理后占用。
4. 保存简短结果：删除文件／空目录数、删除总字节、清理前后工作区占用及净释放空间、保留位置、核验结果和未完成项。净释放空间扣除新增清理记录及再生缓存。核验失败即说明具体缺口并停止依赖操作，不能宣称清理成功或用旧快照覆盖新状态；自动安全审核拒绝的删除不得标为已执行。

清理完成后简报实际释放空间和保留结果；记录留在工作区，不另建比赛报告或演示。不因清理重启已结束的剪辑、判分或导出流程。
