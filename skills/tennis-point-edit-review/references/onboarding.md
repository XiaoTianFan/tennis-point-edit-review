# 首次引导与最少必要询问

## 触发和范围
每场新的网球剪辑任务首次回复，默认用简短自然语言介绍工作方式；除非用户明确说“不用引导／直接开始”等。先检查已给素材、规则、选手及现有项目，不能把介绍写成脱离当前资料的问卷。用户提供信息充分但未跳过引导时，仍简短介绍，然后开始。
这是新比赛的首轮交互，不是在每次加载技能、继续工作、复核回填、技术修正或上下文恢复时重新介绍。若任务只是更新技能、列出统计或明确的单项机械调整，执行该请求，不启动整场比赛介绍。
不另问“是否熟悉本技能”；按现有上下文决定解释长度，陌生用户获得清楚的交付说明，熟悉用户保持简短。

## 一次回复内完成什么
用约2—4句说明逐分精剪与计分、自主回查后少量必要复核、技术统计和估速、默认模板与片尾面板。不得承诺所有疑点都能自动判清，或把单机位估值说成雷达测量。
已有逐分剪好的ChatCut/Pr时间线时，简述将沿用剪辑完成归属分析、统计估速和图形包装，并按[已有时间线接续](workflow.md#已有逐分时间线接续)开始。
若确有缺口，在同次交互合并询问少量必要的背景；不要求用户重新填写已给资料，不一次铺开技术字段或完整统计审核表。
介绍不等于要求用户批准流程；不以“请确认后开始”收尾。可以开展的取证与整理继续进行。确实不能由默认、素材或已有说明确定且影响结果的关键规则，待答案后处理依赖部分，不替用户编约定。

| 用户情况 | 首轮行为 |
|---|---|
| 未跳过、信息充分 | 简短介绍后直接开始 |
| 未跳过、有必要缺口 | 介绍并合并询问缺口，继续不依赖答复的工作 |
| 已跳过、信息充分 | 直接执行 |
| 已跳过、有必要缺口 | 只问该缺口，不附引导；其余工作继续 |
| 同场继续、纠正或回填 | 直接接续当前阶段，不重复介绍或已回答的问题 |

## 背景信息沿用现有规则
按 [输入与规则](inputs-and-rules.md) 核实素材范围/缺口、选手身份、赛制与真实必要参数。最终比分可以未知；开场0:0和结束暂按无未完局均是可核验的工作假设，不例行要求确认。已确认模板优先，无既定样式直接采用正式深蓝青柠模板，不新增样式审批。
未给持拍手时只问一次是否有左手球员；未答按右手假设继续，明确保存来源。已有用户确认不覆盖、不重复问；后续更正按真实动作重核。
只有素材与计分链的具体矛盾在自主回查后仍影响结果，才定向提问并说明证据。不要问尚未出现的假想异常。

## 可按语境缩短的介绍
“我会先逐分精剪并核对计分，遇到疑点先自行回查，只把仍需你判断的片段整理成复核时间线和交互列表。之后完成技术统计、发球初速估算及片尾面板，沿用已确认的视觉模板。”
仅在确实缺少时追加相应问题，不把示例当固定台词或逐字必说内容。
