# 首次引导与最少必要询问

## 触发和范围
每场新的网球剪辑任务首次回复，无论从原片、已剪时间线、复核还是统计阶段开始，默认用简短自然语言介绍从当前起点到目标成片的流程。用户明确说“一口气完成”“不用引导／直接开始”，或上下文已表明熟悉本技能时可省略介绍。先检查已给素材、规则、选手及现有项目，不能把介绍写成脱离当前资料的问卷。
这是新比赛的首轮交互，不是在每次加载技能、继续工作、复核回填、技术修正或上下文恢复时重新介绍。若任务只是更新技能、列出统计或明确的单项机械调整，执行该请求，不启动整场比赛介绍。
不另问“是否熟悉本技能”；按现有上下文决定解释长度。**省略介绍不等于连续执行**：只有用户明确要求全流程一口气完成或持续执行至完成，才跨阶段连续推进；否则按[阶段交付](workflow.md#阶段记录与接续)逐轮接续。

## 一次回复内完成什么
用约2—4句说明当前起点、剩余流程、本轮实质产物及下一步：先完成逐分精剪时间线，再判读计分与基础图层；必要复核和回填可多轮，之后备齐统计/估速数据，统一制作面板与球速图层并验收。只介绍目标所需工作，不承诺全部疑点可自动判清，不把估值说成雷达测量。
已有逐分剪好的ChatCut/Pr时间线时，简述将沿用剪辑完成归属分析、统计估速和图形包装，并按[已有时间线接续](workflow.md#已有逐分时间线接续)开始。
若确有缺口，在同次交互合并询问少量必要的背景；不要求用户重新填写已给资料，不一次铺开技术字段或完整统计审核表。
介绍后直接开展当前已授权阶段的取证与整理。确实不能由默认、素材或已有说明确定且影响结果的关键规则，待答案后处理依赖部分；阶段完成后按[阶段交付](workflow.md#阶段记录与接续)汇报并询问是否继续。

| 用户情况 | 首轮行为 |
|---|---|
| 需要介绍、信息充分 | 简述剩余流程和本轮交付后直接开始 |
| 需要介绍、有必要缺口 | 介绍并合并询问缺口，继续不依赖答复的工作 |
| 已跳过、信息充分 | 直接执行 |
| 已跳过、有必要缺口 | 只问该缺口，不附引导；其余工作继续 |
| 同场继续、纠正或回填 | 直接接续当前阶段，不重复介绍或已回答的问题 |

## 背景信息沿用现有规则
按 [输入与规则](inputs-and-rules.md) 核实素材范围/缺口、选手身份、赛制与真实必要参数。最终比分可以未知；开场0:0和结束暂按无未完局均是可核验的工作假设，不例行要求确认。已确认模板优先，无既定样式直接采用正式深蓝青柠模板，不新增样式审批。
未给持拍手时只问一次是否有左手球员；未答按右手假设继续，明确保存来源。已有用户确认不覆盖、不重复问；后续更正按真实动作重核。
只有素材与计分链的具体矛盾在自主回查后仍影响结果，才定向提问并说明证据。不要问尚未出现的假想异常。

## 可按语境缩短的介绍
“我会先把每分从发球到死球剪好并排入时间线；已有精剪则核实后沿用。下一步由我判分、核对局界并加计分板和发次标签，剩余疑点或比分对不上的问题局再交复核，按需要多轮回填重算。之后备齐统计和球速数据，统一制作五页面板与球速图层，最后验收；每阶段完成后说明当前进度与下一阶段，并询问是否继续。”
背景问题仅在确实缺少时追加，不把示例当固定台词；已要求连续执行时改为说明逐阶段汇报。
