# 每发初速的条件估算与方法选择

目标为离拍初速；中心值、敏感性范围与飞行均速分开。默认逐发证据或最终N/A，不以组均值填标签/统计。实际执行及缺口判定见[取证恢复](serve-speed-audit.md)。

## 先审事件，再选估速方法

先核实同球、真实触拍、源PTS及首次碰撞。放弃/接回抛球、练习挥拍不耗发次；实际尝试却挥空算失误，二发挥空为双误，但无初速，不能填0/补估。一发失误→二发let→重发为1、2、2；let独立记触拍、默认另列，不增加机会或主速度分母。

| 方法 | 证据与条件 |
|---|---|
| A 端点反推 | 触拍与首次落地/碰网的时间夹逼、米制距离及高度；反推初态并扰动输入 |
| B 三维部分轨迹 | 碰撞前同球像素、3×4米制相机及独立接触深度；完整稳定性检查通过 |
| 3.6D/T诊断 | 水平飞行均速，不是初速或独立于A的第二次测量 |

按证据选A/B，合格解不必机械重复。A无端点时评估、补齐B前置并执行，不能因旧脚本仅有A就转均值/N/A。共享时间/标定误差的候选不机械平均；未约束深度的像素/帧不能换为km/h。

画面中过网带不等于碰网。模型只用首次碰撞前段；端点清楚用A，遮挡时尝试已确认仍在空中的早段B，不跨网碰撞、落地反弹或用户剪口。安全截断不冒称碰撞时刻。碰网与let判罚分开，合法落区/现场重发确证后才按[标签时序](serve-speed-overlay.md)切字。

## 物理与米制几何

三维模型`dv/dt=(0,0,-g)-k|v|v+|v|(L×v)`，二维取垂直平面。默认g=9.81m/s²，阻力先验约0.020/m；L为有效升力向量(1/m)，非RPM。未知旋转中心可取0，但须扰动。无风、常数系数、球况都是假设，不任意打折速度。

场地线仅约束地面；网柱/网高等非共面信息和可审查内参帮助建立空中投影。记录控制点、内外参、畸变、公称尺寸/零畸变等假设及留出点检查；不能把地面H当空中3D坐标。用可见基线站位与触拍几何约束深度/高度及范围，不强套统一高度。镜头/裁切变化用静态背景配准或重标定、留出特征验证；不用运动球调相机。

`launch_speed.reconstruct`以RK4/射击法求二维初态；`estimate_endpoint`验证事件/区间再求角点敏感性，非线性显著时补中间点，角点包络不是严格全局界。`partial_trajectory.fit_partial`以RK45/稳健最小二乘拟合初态；一次固定相机、时刻、阻力和升力，随后分别扰动，不同时放开全部未知量。多初值给不同速度却同样贴合像素即不可辨识；完整检查由`serve_recovery.py`执行。

示例球重0.057kg、直径0.067m、空气密度1.2kg/m³、Cd约0.55给k约0.020/m；扰动范围须依本片依据，不套示例，不为覆盖率放宽筛查。

## 统计与补估边界

每发只采用一个合格中心值、逐发等权，按盘/人/发次汇总，再从逐发重算全场；不平均组均值、不取区间上界。回看各人中心最高候选并存fastestCandidateReviewed，范围重叠不宣称真实精确排序。缺测不填0、不改发球机会，披露合格样本覆盖及失误球缺测偏差；敏感性非置信区间，共享误差不随样本数消失。

`impute_same_group`保留作显式请求的补估/诊断，仅用同盘/人/发次/相近条件的独立合格样本，不循环补估。支持包络非目标误差；默认不进视频/均值，明确要求才以“补估”和allow_imputed开关另列。`audit_speed_quality`比较补估影响，不证明其准确。
