# 每发初速的条件估算与方法选择

先区分中心估值、不确定区间、全部发球中中心估值最大的那一发。三者不能互换。原几何算法 3.6 × 触拍到落地端点距离 / 飞行时间仍可作观测诊断，但它不等于离拍初速，也低于曲线路径长度/时间。

## 物理约束

恒定减速度近似下，v0 = D/T + aT/2，需要额外约束 a；仅有 D、T 不足以识别 v0。更适当的基础模型为重力加二次阻力：dv/dt = g - k|v|v，k = rho Cd A/(2m)。必要时增加与速度垂直的旋转升力项。初始高度、终点位置/高度和总飞行时间可用于数值反解初始速度；触网作为飞行段终点，不把网后运动算入减速。

scripts/launch_speed.py 提供垂直平面内 RK4 和两变量射击法，用于条件反解及按盘汇总；没有自动识别球、相机标定或自动确认旋转的能力。输入参数必须由该片证据或注明的物理先验提供。默认值只供开始建模，不是所有比赛的实测常量。更复杂的侧旋需三维模型，不能宣称此二维助手已解决。

根据球的质量、直径、空气密度与阻力系数确定 k；文献约 Cd=0.55 可作为普通网球起始先验，但球况、旋转等带来变化。初速求解应改变触拍/落点定位、时间、高度、几何标定、Cd 和未测旋转，报告敏感性；不统一套固定百分比或把共同模型误差伪当独立噪声缩小。

## 合并与补估

同一发多个候选方法保留各自结果并选择/融合为一个 launchSpeedKphEstimate。完整发球清单是主表，不以跟踪成功者列表代替清单。只有有证据的同组发球可支持模型补估；记录 imputationBasis 与 method=model_imputed，保留可测/重建/补估计数。缺球的最高初速无法被确定，所有最高值仍须标估值。补估不用于填造源触拍时刻、落点或逐帧证据。

整盘平均按所有纳入发球逐次等权；全场平均按全部盘逐发重算。先分别报告每盘、每人一发/二发次数与平均，再可报告全场。任何速度区间的上界都不直接进入最快值或均值。

## Agent内部异常检查
逐盘逐人中心估值最高的候选单独回看原始连续球路：排除球拍/衣服误追、抛球、弹地后轨迹和过短片段；核对独立触拍/终点证据、时间和几何约束。拟合贴近参数边界或不稳定时不能仅因像素残差小就接受，先调整有证据的约束或换方法。fastestCandidateReviewed仅记录agent已执行，不交用户逐项勾选。
scripts/speed_quality.py比较同盘同人同发次的有画面依据模型均值与含补估全量均值，输出补估比例和均值变化；这是敏感性诊断，不是可靠性的证明，也不据此删除慢球或改变等权口径。最高中心估值若来自同组补估，单列来源，不能称已视觉确认最快。
二维反解、三维部分轨迹候选及质量检查工具均可复用；自动球识别、镜头三维标定和事件确认仍需依新录像实现与检验，不把单场脚本或固定相机系数写成通用可靠测量器。输入契约、示例与检查步骤见[发球估速取证](serve-speed-audit.md)。

## 先审事件，再选估速方法

真实尝试发球却挥空属于发球失误、消耗当前机会；但球没有离拍初速，不能记 0 km/h 或用同组补估。主动放弃抛球、接回重抛及练习挥拍不消耗发球机会。一发失误 → 二发 let → 二发重发的发次依次为 1、2、2。let 是独立触拍记录，默认单独展示，不进入主统计的有效发球速度分母；如任务另定纳入范围，必须明确并保持前后一致。

CV 差分、颜色与连续运动筛选只是找球线索；需回看原始连续帧，排除旧球、衣服和球拍等候选。记录实际触拍与首次碰撞的时间夹逼，固定帧率使用真实帧率，VFR 使用原始时间戳。网带在图像中的高度不等于球真正碰网的三维位置。

| 方法 | 适用证据 | 输出与限制 |
|---|---|---|
| A 端点反推 | 可信触拍、首次落地或碰网时间，以及距离、高度 | 以重力、阻力和可选升力数值反解离拍初速；短飞行时间对误判终点尤其敏感 |
| B 三维部分轨迹 | 已校准相机、同球连续像素位置、触拍时间及米制几何约束 | 拟合首次碰撞前的初态；必须通过边界、留出预测和敏感性检查，不能仅看像素残差 |
| C 同组补估 | A/B 不可用，但有同盘、同人、同发次的独立合格样本 | 明示补估并保留支持事件，不伪装成该球实测，不以其他补估循环支持 |
| 飞行均速诊断 | 距离与飞行时间 | 3.6D/T 仅为水平平均速度，不能当离拍初速，也不是与 A 独立的第二次测量 |

A/B 是依据证据选择的候选，不机械平均两个共享同一错误时间或标定的结果；保留选择理由。只有近触拍轨迹且空间尺度可信时，才可近似估计离拍速度，未经深度校准的像素/帧不是 km/h。

## 擦网、碰撞与降级

在第一次碰网处截断飞行模型。不能让无碰撞阻力模型跨过网面碰撞，再用网后落地时间或反弹轨迹外推离拍速度。若碰网时间和几何清楚，用 A 的触拍至首次碰网段；否则尝试 B 的可靠碰网前轨迹；仍不稳定才用 C。不能因为用户觉得速度偏高就任意乘一个折扣。

首次碰网与判定 let 是两件事：触网后还需确认合法落区或采用的现场重发判罚。速度模型在碰网时结束，UI 的“擦网”状态在重发已确证后出现。二发擦网不变回一发；不能把重发的速度套到前一次 let。

## 数值模型、参数和不确定性

三维模型为 `dv/dt = (0,0,-g) - k|v|v + |v|(L × v)`；二维助手使用垂直平面的对应升力近似。默认仍空气、常数阻力和常数升力参数；风、球况和旋转随时间变化没有被自动测量。L 为有效升力向量（单位 1/m），不是球的 RPM。

| 输入 | 当前处理 |
|---|---|
| 触拍、首次碰撞、逐帧时间 | 来自源片事件夹逼，不用剪辑后播放时间求物理速度；检查前后帧误差 |
| 场地距离、相机几何 | 场地线提供米制约束；球离开地面后不能直接用地面单应矩阵当球的三维坐标 |
| 触拍与终点高度 | 来自画面、选手位置和场地几何，携带范围；落地点高度约为地面，碰网高度按实际位置 |
| 重力 g | 默认 9.81 m/s² |
| 二次阻力 k | 起始先验约 0.020/m，须扰动；不是该球实测常量 |
| 升力/旋转 | 无独立证据时中心可取 0，明确这是无升力假设；扰动有效升力评估影响，不声称已识别旋转 |

例如 m=0.057 kg、直径 0.067 m、空气密度 1.2 kg/m³、Cd=0.55 可给出约 0.020/m 的阻力先验；这些是示例，不应覆盖已知环境与球况。合成案例使用 k=0.012–0.028/m、二维升力 ±0.004/m，只用于演示敏感性流程，不能当所有影片的有效误差界。

`launch_speed.py` 用 RK4 积分和射击法反解二维初始水平/竖直速度；`speed_evidence.estimate_endpoint` 先验证事件和输入，再求中心及参数区间角点包络。角点包络是条件敏感性，非置信区间或严格全局误差界。

`partial_trajectory.py` 用 RK45 积分，按已标定相机投影，再以稳健最小二乘拟合六维初态。单次拟合固定相机、触拍时间、阻力及升力，随后分别扰动，不同时自由调整全部未知量。多组初值给出不同速度却同样贴合像素，说明观测约束不足。

三维候选默认须有至少 12 个观测、约 0.18 秒覆盖、无贴边参数、两组交错留出预测及 timing/geometry/drag/lift 四族敏感性检查；1080p 像素残差起点为 2.5 px、留出 3.5 px，速度稳定性起点为 12% 留出差异、35% 敏感性跨度。这些是可调整的工程筛查阈值，不是经雷达验证的误差率。低像素残差、看起来合理或合成数据回归通过，都不足以证明真实速度准确。

平均速度仍逐次等权，先逐盘逐人分一/二发，再按全部纳入发球合并；挥空保留在发球失误/双误统计，速度分母只计真实出球。最高值只取中心估值并单独复核；敏感性范围重叠时不能把细小速度排序称为精确结论。

本次改进加强事件取证、碰撞分段和不稳定模型拒收；没有同步雷达或独立多机位真值时，不宣称提升了某个百分比的绝对测速精度。将来验证应保留独立测试球，报告偏差、绝对误差和覆盖率；不要把用于调方法的争议球同时当性能基准。
