状态：进行中。2026-10-25起，此文件是当前执行任务书；此前
[首轮实验](cv-research-milestone.md)的有界停止条件已被用户替换，测量仍保留。
目标是在完整现存成片语料上，交付与默认agent路线实用品质相当或更好的
可选CV+agent模式，降低总分析/复核时间与token，集成现有Courtside/Edit。
范围包括球员身份/运动/击球层级识别、可选示例确认与适应、近线和终局
选择性原生复核，以及Windows/macOS可移植执行和较低资源设备效率。

## 执行指令

在原始检出持续执行“建基准→研究候选→复现→测量→诊断→修改→回归→
保留/淘汰”的循环。先检查实际成片库及全部相关后代，不用此前的单个
已剪输入代替。完整原录像已删除不阻塞现存成片作为直接输入。

所有现存视频都登记身份、PTS、时长、关联记录和映射状态；记录不完整
的样本进入单列评价类别。读取规范项目、export、账本、review、contacts、
bounces、统计和程序记录，使用已有迁移表解析旧路径，不改写历史。
按独立比赛/原录制分组，替代成片与发球合集不得跨开发/验证/留出分组。
清点覆盖全部库，最终方案处理全部可用整场，分层评估容易与困难样本。

既有agent记录是用户指定的实践参考，不要求先建立完美独立真值。冲突
在现存画面上针对性核查，新增版本化修正；不覆盖旧结果。推理入口只给
视频与独立运行配置，评价端才读取历史答案。比分只能作一致性约束。
剪口不是发球或死球；OCR/图层如使用，须独立开关与消融，不暗中泄漏答案。

研究和实际运行多种可信框架，核对预处理、时序、权重、授权与机位域。
隔离配置GPU环境，保留全局环境和其他服务；公开模型与普通本地实验可
直接执行，不购买云资源。每次改变写假设、固定开发集、错误分析、资源/
覆盖/延迟/复核变化，保留最好配置和可回退版本。

逐步完成球场几何、球候选/轨迹、触拍/落点、发球/活球/死球、分/回合
提案、有证据支持的统计及agent例外处理。未知仍保留，但广泛拒判是要
降低的错误负担，不能用全部拒判或回退全量原流程通过验收。

长视频须有进度、分块、恢复、输入/配置指纹、资源界限与明确失败；
观察、推断、agent采用和用户批准分层。完整导入→分析→复核→保存→
重开及隔离测试渲染均需实测。保留既有七套模板、源PTS、原生精确证据、
legal-serve分母和一次视频/音频编码契约。内部测试输出不冒充用户成片
批准；原片/现存成片不改写；破坏性清理和正式交付仍按原授权边界。

阶段性改动本地提交并更新操作文档，不新建worktree、不远程发布、不
同步账户Skill。实验/权重/视频/私有标签在主检出ignored outputs中。
遇到性能差或误检继续诊断；仅真实外部前提导致无法做任何有意义工作时
提出具体问题。不要以“有条件可行”“需要进一步研究”结束可执行工作。

## 2026-10-25 范围细化与实施约束

### 球员与击球

球员身份、场地位置（仅几何支持时）、运动、姿态和击球类别是核心能力。
人体框、手腕响应或近远端关联不等于身份/击球识别完成。处理换边、左右
手、近远端尺度差、邻场人员和观众，分别测身份切换、类别混淆、覆盖、
不确定性和修正工作量。保留结构化层级：正手/反手/头顶/发球等动作家族，
落地后击球/截击等接球方式，以及平击/上旋/切削、kick等有证据的旋转或
风格。明确覆盖正反手、正反手切削、正反手截击、高压和发球；弱画面不
支持的子类型为unknown，并保留改进待办，不能删除困难类别。

### 可选短片示例确认

提供可跳过的引导预检：提出数量少、动作/视角多样的短运动片段，让用户
确认或修正身份、惯用手和动作标签，agent可以协助找例和判读。每条示例
记录原始PTS、确认者、observed/agent-proposed/owner-confirmed状态以及
版本；支持未知、追加、撤销和可复用的球员/会话档案。未确认示例不冒充
用户标注，一例不保证泛化。先比较轻量特征检索/原型校准或小型适配器，
数据和错误证据支持后再比较微调。完整计入挑选、确认、训练与后续复核
成本；区分陌生球员/机位泛化与会话内辅助适应。校准片段不能进入计分
评价，支持集/查询集协议在解封留出前声明，未来修正不能回灌盲测结果。
此设计受用户描述启发，不声称知道SwingVision内部训练机制。

### 可检查的观察与联合推断

球与球员观察采用独立可读契约，共享源身份、PTS、坐标体系和不确定性；
融合层再使用球路、人物动作、球场几何和时序推断触拍、类别、弹地、活球、
死球和分结果。二维邻近/手腕投影重叠不能单独成立触拍，遮挡与前后景
混淆保留未知。测量共用解码、时间索引、裁图/特征缓存、批处理和自适应
采样的收益；快小球与慢人体可以用不同分辨率/频率。在疑似触拍、落地和
终局附近提高细节，同时审计低频阶段漏事件。比较模块化与融合方案，不
强制单网络，也不在没有成本证据时重复昂贵全片解码。

### 低机位业余录像

低机位、远端缩短/遮挡、场线不全和远端小球是主要工作条件，同时保留
转播录像支持。逐一核查模型训练域，不笼统声称开源模型均使用同种数据。
按机位、场端、可见性、球尺寸、遮挡和人物尺度分层。标定和定位保存
误差/不确定范围，米制坐标不成立时保留像素观察；空中球的场平面投影
不是落点，不补造隐藏场线和精确压线距离。需要训练时按录制组隔离。

### 近线与终局选择性复核

只有落地证据、相机/场线标定及经验误差界共同支持足够裕量时，清晰界内/
界外才可自动通过；检测响应本身不是距离误差界。近线、时间/位置不确定、
缺测、模型分歧和几何不可靠触发针对性原生逐帧/短序列agent复核。末拍和
拟议结束时刻优先执行终局一致性与向前核验，剪口/下次发球只作锚点。
像素无法解决时保留未知并在必要处呈现用户决定。量化clear/close/unknown、
错误的高置信判断、升级率、终局漏检、复核命中率、帧数/token/时间及最终
修正量；抽查自动通过案例，不能用隐藏错误换节省。与完整agent基线按
可比最终质量比较。

### 可移植性和资源效率

至少目标Windows与macOS，保留功能完整的CPU路径与明确能力检测/回退。
RTX 4080只作研发加速，不作运行前提或最低硬件代表。路径、媒体工具、
依赖和模型载入可移植；按算子、许可和实测等价性评估Apple Silicon MPS、
Core ML、ONNX等选择，不强制CUDA。明确Mac架构/最低环境；无macOS执行器
时完成可做的移植工作并列出真实设备待验项，不声称Intel/Apple Silicon已
测，不因此停止其他工作。当前工作站禁用GPU只证明该工作站CPU行为。

近实时/实时是认真推进的优化目标（处理时间/片长比趋近或低于1），不是
现成通过声明，也不包含开发iOS应用。分别记录解码/校准/推理/证据/agent/
确认和总时间、硬件、分辨率/FPS、配置、内存、质量及复核成本。正确性稳定
后按剖析结果减少重复解码、裁图和时序窗开销，评估小模型、缓存、混合
精度、量化、蒸馏与转换，并重测质量和后端等价性。

## 验收矩阵与冻结程序

下列是预登记工程目标，不是已达成结果。先在开发集测当前agent基线和
可用参考误差，冻结数值与理由，再解封留出集。基线若揭示标签分辨率
不支持某指标，应改为明确可测指标并留版本历史，不能为迁就差结果降低
目标。留出一旦用于调参即转为开发数据，后续用独立组交叉验证。

| 门 | 预登记要求 | 证据 |
|---|---|---|
| G01 语料完整性 | 实际目录100%视频登记；完整整场100%处理或有具体外部失败原因，不能静默剔除 | 版本manifest、输入哈希与PTS覆盖 |
| G02 参考/泄漏 | 所有采用标签有来源与映射状态；推理不读规范答案；同比赛分组无泄漏 | 独立inference/evaluation输入清单与hash |
| G03 球定位 | 分层含正负例、每组可见球评价；初始目标10px容差F1≥0.90，逐组报告，不能只报有值均值 | 固定采样、可见/遮挡/未知分层、错漏分布 |
| G04 几何 | 支持机位每段可稳定标定；保留验证点中位误差≤5px、P95≤10px；初始设置≤2分钟/机位 | 未用于拟合的点、相机变化验证；无米制精度冒称 |
| G05 事件 | 可观察的触拍/落点初始目标P/R均≥0.90、时刻容差50ms；不可观察分层 | 一对一事件匹配、误检/漏检和时间误差 |
| G06 分边界 | 发球/首次死球初始召回≥0.95、精度≥0.90；起点0.5秒、结束0.2秒容差；不使用编辑剪口代替 | 全场事件参考、截断状态、前后核查 |
| G07 最终质量 | 混合流程修正后有效分归组/采用赢家与可信参考一致；冲突须有原生证据；无静默漏分 | 完整逐分链与差异复核，未知独立计数 |
| G08 统计 | 有支持的统计修正后与同版本规范计数一致；不同定义/旧模型填补单列；未知/N/A不制造分母 | 逐项差异、事件谱系、legal-serve约束 |
| G09 效率/复核 | 固定配对任务实测总墙钟及可用token≤agent基线50%；需视觉例外核查的事件≤25%，修正量单列 | 解码/推理/证据/agent/用户分别计时；token缺测不能报通过 |
| G10 运行可靠性 | 全场完成、可恢复且不重复/漏帧；源/配置变化拒绝混用；资源可控、错误可诊断 | 完整运行、一次中断恢复、指纹与失败测试 |
| G11 工作台/渲染 | 全场导入、定位、复核、保存、重开、隔离测试渲染通过；旧工程与批准不改写 | 浏览器/API记录与源绑定测试输出 |
| G12 分发/维护 | 依赖/模型来源版本可复现、授权可分发或外置；包验证/构建通过；默认agent路线可用 | 安装说明、版本锁、测试与本地提交 |
| G13 球员/击球 | 身份跨换边、惯用手、位置/运动和完整请求类别均有显式结果或未知；按类报告覆盖/混淆/身份切换与修正成本，数值目标在实测基线后冻结 | 独立球员观察、层级标签、来源和分层误差 |
| G14 示例辅助 | 可选短片确认与版本化档案可用；泛化与会话内辅助分别比较，支持/查询无交叉，成本包含选例/确认，未知可跳过 | 通用/示例辅助配对协议、确认者与版本、完整成本 |
| G15 选择性复核 | clear/close/unknown有可测误差与几何依据；末拍向前核验、升级与自动通过抽审可执行，最终质量与全agent基线可比 | 错误高置信决策、漏终局、升级/复核精度、帧/token/时间 |
| G16 平台/后端 | Windows与macOS目标、CPU功能路径、能力检测和回退明确；实际验证按架构/设备单列，无机器不能声称已验 | CPU/GPU及可用Mac后端一致性、依赖和路径验证；Mac缺口清单 |
| G17 较低资源效率 | 完整运行与推理分开报告；追踪处理/片长比趋近≤1，优化后重测质量；不得将高端GPU或本机CPU当低端/Mac实测 | 代表性可用后端、硬件/资源/帧率、全流程成本与未知 |

目标不要求单目自动裁判或100%机器正确，但G07/G08最终可用结论、G09
成本和复核负担不能靠全部交还原流程满足。原始未剪录像的泛化另列；
不能把成片试验宣称覆盖已经删除的等待过程。
