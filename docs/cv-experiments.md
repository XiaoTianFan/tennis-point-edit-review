# 混合视觉实验账本

当前目标与验收以[生产任务书](cv-production-plan.md)为准。每项记录包含
假设、固定数据/配置、代码/权重版本、结果、失败诊断、取舍和下一步。
真实素材和逐帧数值留在ignored任务目录；本文件不承载用户私有标签。

|---|---|---|
| P000 | 旧15秒CPU试验检查模块化观察/工作台接口 | 历史证据，见首轮报告；速度、覆盖、几何及事件不足，作为待改进基线 |

| P006 | 新检测器能带动已有事件逻辑，而非仅改善球响应 | 全场后处理135.96秒，5,640帧选定轨迹、37个转折候选。20个保留发球首次落点中11个在50ms内有候选；21个触拍中仅6个在10px/50ms夹逼范围内有球候选。暴露远端与触拍缺口；其他未标注回合事件不能计为负例 |
| P007 | 场地失败主要来自关键点网络域偏移，可用少量agent线语义+原生像素拟合改善 | 首帧14通道仅1个有响应，其余最大值约0.02（另1个0.15），RGB交换无改善；不是几何门过严。六条实际场线自动细化后6点一致拟合，两个未参与四点试拟合的交点误差0.14/2.36px。仅单帧近场，远场/跨时刻/设置成本仍待验证 |
| P008 | 原生区域裁切推理能恢复被全幅下采样丢掉的小球 | 全场第二视图183.04秒；已标注发球落点的10px/50ms夹逼内候选覆盖16/20→19/20；触拍全幅6/21、裁切3/21、两者候选并集9/21。并集只是可用候选上界，不是选定轨迹正确率或整体F1 |
| P009 | 时间戳音频冲击可补充触拍/落地观察 | 连续音频PTS已核对；提取368个未分类瞬态，1.12秒。环境球场、脚步与传播延迟明显，单独音频不能作触拍真值；继续视觉联合验证 |
| P010 | 分块提交与指纹围栏能可靠恢复全长球检测 | 新流式接口完成真实整场：1,800帧检查点后恢复至14,589帧，与此前不中断运行的PTS、候选数及坐标完全一致。23帧合成非零起点VFR覆盖恢复、异常、孤立未提交文件、篡改拒绝。259项包/仓库测试通过；仍只证明观察执行可靠性 |
| P011 | 容许短缺测的分段拟合比连续7帧转折规则更适合远端 | 保留实际观察，不生成插值球；两视图独立候选在20个发球落点中的50ms命中达到16/20，较原11/20改善。候选尚未融合，误报/非发球回合事件与剩余4处漏检需要原生序列核查；未通过事件P/R门 |

权重留在ignored任务目录，不随技能包分发。RacketVision checkpoint经精确
哈希检查与窄范围安全类型允许列表提取为纯Tensor state_dict，之后按
`weights_only=True`读取；未使用不受限pickle加载。

当前选择：WASB FP16作为开发主候选；继续检查正负例、全场事件召回和
场地跨时刻有效性。留出两场尚未用于模型试验；验收目标还没有按实测
agent成本冻结，不解封留出。所有上述耗时均为相应实验范围，不冒充整套
工作流总耗时或token节省。

v26.3新增`cv_stream.py`/`cv_wasb.py`的全长观察执行层，保留有界接口及默认
agent路线。分块按源PTS提交，恢复核对源/配置/代码/权重/运行时及块哈希；
失败与检查点不发布完成结果。多视图保留来源，不默认融合或判为多个球。

这次运行与单独进程作精细性能排名。七个JSX模板、现有工程和用户批准未改。
