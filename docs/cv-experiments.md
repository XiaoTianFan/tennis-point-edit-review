# 混合视觉实验账本

当前目标与验收以[生产任务书](cv-production-plan.md)为准。每项记录包含
假设、固定数据/配置、代码/权重版本、结果、失败诊断、取舍和下一步。
真实素材和逐帧数值留在ignored任务目录；本文件不承载用户私有标签。

| ID | 假设与测试 | 状态 / 决定 |
|---|---|---|
| P000 | 旧15秒CPU试验检查模块化观察/工作台接口 | 历史证据，见首轮报告；速度、覆盖、几何及事件不足，作为待改进基线 |
| P001 | 全量成片库应包含此前五工程之外的旧比赛 | 已登记8个文件（7场+1发球合集），共60.5分钟、217,675帧；逐流PTS检查完成。5场由保留映射与成片哈希关联，2场旧时间线由准确时长关联，视觉对应核查继续；合集保留为辅助组 |
| P002 | GPU可消除CPU实现的大部分推理开销 | 固定510帧、旧模型及逻辑：412.37秒→30.44秒；候选143帧、选定134帧与CPU计数一致。隔离运行环境使用已有CUDA基座，只读继承；未修改全局环境。计数一致不等于逐像素结果完全相同 |
| P003 | WASB的网球权重/多帧融合优于旧强度分类模型 | 官方RGB/仿射/ImageNet预处理、3入3出：510帧7.12秒；FP16为6.23秒。12个既有正例中11个在5px内、无拒判，旧模型7个/3个拒判。小样本、非盲、无负例，只用于诊断。正确重置接缝后找回原漏掉的落地候选 |
| P004 | WASB可在整场视频保持有界GPU资源与完整帧覆盖 | 开发场14,589帧全部处理，176.86秒，峰值GPU分配约517MiB；5,736帧有模型候选。包含40秒统计定格，检测率不等于可见球召回。球检测通过全长运行，但尚无断点恢复或完整流程通过声明 |
| P005 | RacketVision多运动权重+背景有利于当前机位 | 复现官方BGR、背景+4帧、最后输出、bbox中心；同510帧总46.27秒（背景生成22.14秒），推理4.93秒。12正例10个在5px、1个缺测。首轮未超过WASB，保留来源和结果，暂不选主后端 |
| P006 | 新检测器能带动已有事件逻辑，而非仅改善球响应 | 全场相机/接缝/轨迹/事件处理进行中；历史发球触拍/终点先独立映射，删除的一发记录为未保留，其他未标注回合事件不能计为负例 |
| P007 | 场地失败主要来自关键点网络域偏移，可用少量agent线语义+原生像素拟合改善 | 首帧14通道仅1个有响应，其余最大值约0.02（另1个0.15），RGB交换无改善；不是几何门过严。六条实际场线自动细化后6点一致拟合，两个未参与四点试拟合的交点误差0.14/2.36px。仅单帧近场，远场/跨时刻/设置成本仍待验证 |

哈希检查与窄范围安全类型允许列表提取为纯Tensor state_dict，之后按
`weights_only=True`读取；未使用不受限pickle加载。

当前选择：WASB FP16作为开发主候选；继续检查正负例、全场事件召回和
场地跨时刻有效性。留出两场尚未用于模型试验；验收目标还没有按实测
agent成本冻结，不解封留出。所有上述耗时均为相应实验范围，不冒充整套
工作流总耗时或token节省。
